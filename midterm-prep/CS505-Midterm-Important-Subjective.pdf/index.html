  1. What is virtualization? How is virtualization achieved?
    Topic: Virtualization Fundamentals

    Virtualization is the simulation of hardware devices or features using software, in which a single system pretends to be two or more systems. It is used to create a virtual version of something, such as a network. Virtualization is achieved through virtualization software called a hypervisor. The hypervisor creates virtualized versions of the physical resources and allocates them to virtual machines (VMs). Each VM operates as if it were a physical machine and can run different applications, operating systems and services.

  2. Why is virtualization used? List its main benefits.
    Topic: Virtualization Fundamentals

    Virtualization is used for the best use of resources, flexibility and scalability, increased agility, disaster recovery, increased security and cost saving. Its main benefits are: (1) Resource utilization - virtualized versions of physical resources use the same hardware more effectively. (2) Scalability and flexibility - resources can be scaled up or down as needed without physical changes to the underlying infrastructure. (3) Improved disaster recovery and business continuity - replicas of the production environment can be created and quickly activated in the event of a disaster without affecting the end user. (4) Increased security - sensitive applications and data can be isolated and secured, making it harder for malicious actors to access them.

  3. Name and briefly explain the main types of virtualization.
    Topic: Virtualization Fundamentals

    (1) Server virtualization: allows multiple virtual servers to run on a single physical server by sharing the underlying hardware resources. (2) Desktop virtualization: allows multiple virtual desktops to run on a single physical machine, where each user has a separate desktop environment. (3) Application virtualization: allows applications to run on a virtualized operating system, separate from the host OS. (4) Storage virtualization: pools storage resources from multiple physical devices into a single virtual storage device, making storage easier to manage. (5) Network virtualization: creates virtualized versions of physical network devices such as switches and routers, so multiple virtual networks can run on a single physical network. (6) Hardware virtualization: creates virtualized versions of physical hardware devices, such as GPUs, so multiple virtual devices can run on a single physical device.

  4. What is application-level virtualization? How does it work?
    Topic: Application Virtualization

    Application-level virtualization is a technique in which client applications are hosted remotely instead of being installed on the client's local devices. The local devices provide the physical resources like CPU and RAM that may be required to run the software, but nothing is installed locally on the device itself. This technology separates the application from the underlying operating system, so the execution of the application is independent of the OS. In this environment, the application actually runs remotely but virtually runs locally.

  5. Discuss the benefits and limitations of application virtualization.
    Topic: Application Virtualization

    Benefits: (1) Reduced cost. (2) Cross-platform operations - Windows applications can run on Linux and vice versa. (3) Simplified management - an IT admin can manage and maintain applications centrally across an organization rather than installing them on every user's machine. (4) Security and stability are improved by isolating the application from the OS. (5) It prevents conflicts with other virtualized applications. (6) It permits users to run multiple application instances. Limitations: (1) Single point of failure - launching all applications on servers increases the risk of failure. (2) Bandwidth requirements - sufficient bandwidth is required for streaming applications to end-users. (3) Problematic applications - some applications need system drivers and do not work as virtualized applications. (4) High initial investment in migrating data to the data center or cloud. (5) Challenging quick scalability - ensuring the requisite software, storage, security and resource availability is a tedious job.

  6. Compare desktop virtualization with application virtualization.
    Topic: Application Virtualization

    Desktop virtualization is the practice of hosting a desktop operating system and applications within a virtual machine on a centralized server or cloud; each VM is called a virtual desktop, and the desktop runs as a virtual machine in a secure data center. Application virtualization is the practice of hosting applications only on a remote host or server; each application is called a virtual application, and the applications actually run on the secure server. In both techniques, the desktop/applications are decoupled from the hardware system that accesses them, different vendors' desktops/applications can be hosted, and users may connect from anywhere, anytime, using a desktop PC, laptop, thin client or mobile device.

  7. Name the popular application virtualization solutions and explain the Microsoft App-V architecture.
    Topic: Application Virtualization

    Popular solutions are VMware ThinApp, Microsoft App-V, Citrix Virtual Apps and Desktops, and Parallels Remote Application Server (RAS). In Microsoft App-V, the server side requires App-V server components: the App-V Management Server, the App-V Sequencer and the App-V Streaming Server. Virtual applications are installed on a centrally managed server. The App-V Sequencer converts application data into an App-V package for virtualized delivery, and the package can be streamed down to the clients on demand and cached locally. On the client machine, the App-V client is installed; it runs the virtualized applications on user devices and presents a list of applications to which that user has access.

  8. What is a data center? Describe the components of a data center.
    Topic: Software-Defined Data Center

    A data center is a place that gives people access to applications and data through a complicated network of computer and storage systems. Its components are: (1) Computer system - the servers used to process, store and distribute the data. (2) Telecommunication system - equipment such as routers, switches and firewalls used to connect the computer systems to the outside world. (3) Storage system - used to store the data processed by the computer systems, such as customer records, financial information and business applications. (4) Power systems - provide continuous power to the equipment and are designed to be highly reliable and redundant. (5) Cooling systems - keep the temperature down and prevent the equipment from overheating. (6) Security systems - protect data and equipment from unauthorized access through physical measures (access control, video surveillance) and logical measures (firewalls, intrusion detection systems).

  9. What is a software-defined data center (SDDC)? Explain its three purposes: abstraction, pooling and automation.
    Topic: Software-Defined Data Center

    A software-defined data center (SDDC) keeps the data center up to date with the latest technology by using software-based components to manage and automate the environment. It provides a better way of controlling the data center, reduced IT complexity and centralized management. Its three purposes are: (1) Abstraction - hiding the underlying physical hardware (physical CPU, RAM, network) from the user, so users view and interact with resources as if they were dedicated to them, even though they are shared. (2) Pooling - grouping together physical resources such as CPU, memory, storage and network bandwidth so that they can be shared by multiple virtual machines, improving utilization and reducing cost. (3) Automation - automating the delivery of IT services.

  10. Compare the design of a physical data center with the design of a virtual data center.
    Topic: Server Virtualization Architecture

    In a physical data center, physical servers are running, and the applications and operating system run directly on the physical server; an Ethernet switch is linked up with L2 and L3 switches, plus IP-based storage. In a virtual data center, a hypervisor layer is introduced on the hardware so that several virtual machines can run on minimal hardware, with the physical resources shared among the VMs instead of being tied to one server.

  11. How are resources shared in a virtual data center? State the VMware limits for vCPU, memory and vNICs.
    Topic: Server Virtualization Architecture

    In a virtual data center, the physical host's CPU, memory and network resources are shared among the virtual machines. The maximum number of vCPUs on a VM depends on the number of logical CPUs on the physical host and the type of OS on the VM; VMware supports up to 128 vCPUs on one VM. The maximum virtual memory on a VM depends on the maximum memory available on the physical host and the type of OS on the VM; VMware supports up to 6 TB of virtual memory on one VM. A VM supports up to 10 vNICs (virtual network interface cards).

  12. Name the popular server virtualization software and describe any two.
    Topic: Server Virtualization Architecture

    Popular server virtualization software includes VMware vSphere, Microsoft Hyper-V, Citrix Hypervisor, Nutanix AHV and Red Hat Virtualization. VMware vSphere is a complete virtualization platform from VMware that includes a hypervisor, vCenter Server for centralized management, and a suite of tools for managing virtual machines, storage, networking and security. Microsoft Hyper-V is a Microsoft virtualization product (hypervisor) that allows you to create and run multiple VMs on a physical host; it is a Type-1 hypervisor that runs directly on the physical hardware and provides a direct interface to the physical resources. Citrix Hypervisor is a Type-1 hypervisor optimized for virtual app and desktop workloads, built over the Xen virtual machine hypervisor. Nutanix AHV is a Type-1 hypervisor that runs directly on the physical hardware without the need for a separate operating system.

  13. What is a hypervisor? Describe the components of a hypervisor.
    Topic: Hypervisor

    A hypervisor is a software layer that creates and manages virtual machines (VMs). It acts as a virtualization layer between the physical hardware and the VMs, allowing multiple VMs to share the underlying hardware resources of the host and multiple operating systems to run on a single physical server. Its components are: (1) Virtual Machine Monitor (VMM) - the core component that manages virtual machines. (2) Virtual Devices - NICs, virtual hard drives and virtual switches that provide virtual versions of physical devices. (3) Virtual Machine Executables (VMEs) - virtual versions of operating systems that run on virtual machines. (4) Drivers - provide access to the physical hardware resources of a host device. (5) Management Interface - allows administrators to create, manage and monitor VMs. (6) Virtual Machine File System (VMFS) - stores virtual machines and their configuration files.

  14. What is vCenter Server? What is ESXi?
    Topic: Hypervisor

    vCenter Server is used to manage the entire virtualization data center centrally, instead of manually visiting the data center. Through its management console, administrators can also perform day-to-day tasks, for example taking snapshots. ESXi is VMware's hypervisor: it is installed directly on a physical server like an operating system, takes the physical resources from the physical server and assigns them to virtual machines, which reduces data center space, power and IT administration effort. The vSphere version described in the lectures is 6.7.

  15. Differentiate between Type-1 and Type-2 hypervisors, giving examples of each.
    Topic: Hypervisor

    Type-1 (bare-metal) hypervisors run directly on the host's physical hardware, are not dependent on any host operating system, control the underlying hardware resources of the host and provide virtualized environments for guest operating systems. Examples: VMware vSphere (used in large enterprise environments and cloud infrastructures), Microsoft Hyper-V (widely used in enterprise environments with a strong Microsoft presence) and Citrix XenServer (strong presence in financial services and healthcare). Type-2 (hosted) hypervisors run as an application on top of a host operating system; the OS is installed first and then the hypervisor application is installed on it, through which multiple VMs are created. They are commonly used for software development, testing and personal desktop virtualization where high performance is not critical, and they are less secure than Type-1 because they are vulnerable to attacks on the host operating system. Examples: Oracle VirtualBox and VMware Workstation.

  16. Write short notes on VMware Workstation, VMware Fusion and Oracle VirtualBox.
    Topic: Hypervisor

    VMware Workstation is VMware's Linux- and Windows-focused Type-2 platform. It comes in two flavors: Pro, a paid version that allows users to run multiple operating systems on a single PC, and Player, which is free for personal use and supports only a single guest OS. Workstation supports snapshots and cloning of VMs and virtualized hardware such as virtualized GPUs and USB devices. VMware Fusion is the company's macOS-focused offering, which lets Mac users run a large range of guest operating systems, e.g. run Windows applications on Mac OS. Oracle VirtualBox is a Type-2 hypervisor running on Linux, Mac OS and Windows; it supports a wide range of host and guest operating systems and is used for personal virtualization, software testing and development.

  17. List the steps to install ESXi and create a virtual machine on it.
    Topic: ESXi and VirtualBox

    Installation steps: (1) Download the ESXi image from the VMware website. (2) Find the hardware-compatible image. (3) Boot the system with the bootable ESXi image. (4) Press Enter to continue. (5) Scan and select the disk to install ESXi (a single disk is used by ESXi). (6) Complete the installation and remove the ISO image. Creating a virtual machine: the recommended steps are (1) create a datastore (and a directory on the datastore), (2) upload the image of the operating system, and (3) install the virtual machine.

  18. What is Oracle VM VirtualBox? State its main features.
    Topic: ESXi and VirtualBox

    Oracle VM VirtualBox is a cross-platform virtualization product used for virtualizing x86 and AMD64/Intel64 computing architectures. It is freely available as open source software under the terms of the GNU General Public License (GPL). It runs on all major operating systems including Windows, Linux, Mac and Solaris, and different versions exist for these hosts. It has both a graphical interface (GUI) and a command-line interface (CLI). Using VirtualBox, multiple guest operating systems can be installed as VMs on the host OS, for example Windows 7 or Linux as guest on a Windows 10 host. VirtualBox supports both hardware and software virtualization, and it is recommended for small and mid-range projects.

  19. Compare VMware and VirtualBox.
    Topic: ESXi and VirtualBox

    (1) Vendor/type: VMware is a virtualization platform developed by VMware and is a Type-1 hypervisor; VirtualBox is developed by Oracle Corporation and is a Type-2 hypervisor. (2) Virtualization support: VMware supports hardware virtualization; VirtualBox supports both software and hardware virtualization. (3) Licensing: VirtualBox is an open source product, while VMware's Workstation Player is free but other VMware products require a paid license. (4) Host support: VMware Workstation works on Windows and Linux, and VMware Fusion/Fusion Pro is needed for macOS; VirtualBox can be installed on Windows, Linux, Solaris, MacOS and FreeBSD. (5) Disk formats: VMware supports the VMDK format; VirtualBox supports VDI, VHD and VMDK. (6) Snapshots: VMware supports snapshots on its paid products, while VirtualBox supports snapshots free of cost. (7) Performance: VMware virtual machines run faster, while VirtualBox VMs run slower comparatively. (8) Recommendation: VMware is recommended for enterprise projects; VirtualBox is recommended for small and mid-level projects.

  20. What is Hyper-V? State its advantages.
    Topic: Hyper-V

    Hyper-V is a virtualization platform by Microsoft through which multiple isolated environments can be created on a single physical server. It is a Type-1 hypervisor and can be enabled from the Windows operating system. Its advantages are: (1) cost can be reduced; (2) hardware can be utilized with full capacity; (3) it provides flexibility; (4) different environments, like testing and production environments, can be created; and (5) power consumption can be reduced.

  21. Describe the lab steps to enable Hyper-V and create a virtual machine in Windows.
    Topic: Hyper-V

    Step 1: Enable Hyper-V in Windows 10 Pro or Windows Server - go to Apps & features, then Programs & Features, then 'Turn Windows features on or off', and check the Hyper-V option from the list; Hyper-V then becomes accessible from the search bar. Step 2: Create a virtual machine - open Hyper-V Manager, and from the Actions menu click New and then Create Virtual Machine, configuring it according to your needs. Step 3: Install the operating system - select the created VM, click Actions, then Connect, and proceed with the Start option; the OS installation starts. Step 4: Play with the VM state - turn it off if it is running or turn it on if it is off, and check the shutdown status by right-clicking the VM. Step 5: Explore the settings option of the VM, for example increase the memory or CPU according to your workload.

  22. Compare Hyper-V with VMware.
    Topic: Hyper-V

    (1) Hyper-V is Microsoft dependent, while VMware provides a complete ecosystem for virtualization. (2) Hyper-V uses checkpoints, while VMware uses snapshots. (3) Hyper-V has the Live Migration tool for migrating workloads, while VMware uses vMotion for migration of workloads. (4) Hyper-V provides support for Linux; VMware provides fault tolerance and disaster recovery. Both VMware and Hyper-V are market players of virtualization, and Hyper-V is a Type-1 hypervisor.

  23. What is a virtual machine? What are its uses?
    Topic: Virtual Machines

    A virtual machine (VM) is a virtual representation of a physical machine. It is also called a guest machine or virtual server. It provides the same functionality as a physical machine or server, and it uses the resources of the physical machine through virtualization software (hypervisor). Each virtual machine has its own operating system, called the guest operating system. Uses of VMs: a VM is used as a substitute of a physical server in a data center; it reduces data center cost; it provides different types of virtualization such as hardware virtualization and desktop virtualization; it provides scalability (a new VM can be added or an existing one upgraded); and migration of a VM is quite easy.

  24. Discuss the merits and demerits of virtual machines.
    Topic: Virtual Machines

    Merits: (1) Multiple operating systems can run on a single host. (2) Reduced cost - several VMs can be hosted on a single physical server, reducing the cost of the data center in space and power. (3) Portability - a VM can be easily migrated across the virtual environment. (4) Security - VMs run in isolation, so if security is compromised in one VM, other VMs are not affected; if one VM fails, the other machines are not affected. (5) Incompatible software can be run, as the OS and applications are decoupled from the underlying hardware/OS. (6) Administrators can simplify backup, disaster recovery and new deployment. Demerits: (1) Cost - running VMs with cloud computing is expensive. (2) Low performance - VM performance is less than that of a real machine. (3) Less efficiency - a VM accesses hardware indirectly and is less efficient than a real machine. (4) Single point dependency - the VM relies on the shared resources of the host machine; if the physical host goes down, all the hosted VMs become useless.

  25. Name the files of a virtual machine and briefly describe each.
    Topic: Virtual Machines

    (1) vmname.nvram - the VM BIOS configuration file. (2) .vmx - the configuration file of the VM, which contains information about the hardware settings. (3) .vmsn - the VM snapshot data file. (4) .vmem - the virtual machine paging backup file. (5) .vmdk - contains the virtual disk characteristics. (6) vmware.log - stores the log activities of the VM.
