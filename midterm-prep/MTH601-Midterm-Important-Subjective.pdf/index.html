  1. What is Operations Research? List the steps of the OR approach to problem solving.
    Topic: Introduction to Operations Research

    Operations Research (OR) is the application of scientific and quantitative methods to decision making. It provides a quantitative basis for taking the most suitable decision in problems involving the allocation of scarce resources among competing activities. The OR approach to problem solving consists of the following steps: (1) Observation - identifying that a problem exists in the system; (2) Definition of the problem - the objective must be clearly defined; (3) Construction of the model - building a mathematical model representing the system; (4) Solution of the model - obtaining the optimum solution using OR techniques; (5) Validation of the model - checking that the model represents the real system adequately; (6) Implementation of the results - putting the solution into practice and monitoring it. OR is an ongoing process, since the system is observed again after implementation.

  2. Define the following: (a) Dummy activity and its use (b) Looping error in a network (c) Dangling error in a network.
    Topic: Network Analysis: PERT and CPM

    (a) Dummy activity: A dummy activity is an imaginary activity which consumes no time and no resources. It is introduced in a network to maintain the proper precedence relationship between activities which are not connected by an event, and to keep the identity of activities unique. It is represented by a dotted line. (b) Looping error: Looping (cycling) occurs when a sequence of activities forms a closed cycle, so that one comes back to an earlier event. A loop makes the project endless and is not allowed in a network. (c) Dangling error: Dangling occurs when an activity is left disconnected, i.e. an intermediate event has no outgoing activity (other than the final event). Every activity except those ending at the final event must have a successor; a dangling activity must be connected to the final event, if necessary through a dummy activity.

  3. What is PERT? How is it different from CPM?
    Topic: Network Analysis: PERT and CPM

    PERT (Program Evaluation and Review Technique) is a network technique used for planning, scheduling and controlling projects whose activity times are uncertain. In PERT each activity has three time estimates - optimistic (to), most likely (tm) and pessimistic (tp) - and the expected time is computed as te = (to + 4tm + tp)/6, the activity times being assumed to follow a beta distribution. CPM (Critical Path Method) is used for projects with deterministic (single, known) activity times and is activity/cost oriented, emphasizing the trade-off between project time and cost. In short: PERT is probabilistic and event oriented, used mainly for research and development projects; CPM is deterministic and activity oriented, used mainly for construction type projects. The network diagrams of the two are the same except for the activity times.

  4. Define the following terms: (a) Earliest Start Time (b) Earliest Finish Time (c) Latest Start Time (d) Latest Finish Time.
    Topic: Network Analysis: PERT and CPM

    (a) Earliest Start Time (EST): The earliest time at which an activity can be started, assuming all its preceding activities are completed as early as possible. It is obtained by the forward pass. (b) Earliest Finish Time (EFT): The earliest time at which an activity can be finished; EFT = EST + duration of the activity. (c) Latest Start Time (LST): The latest time at which an activity can be started without delaying the completion of the project; LST = LFT - duration of the activity. (d) Latest Finish Time (LFT): The latest time at which an activity can be finished without delaying the project. It is obtained by the backward pass from the project completion time.

  5. For the project activities given below, calculate EST and EFT of each job. If the project completion date is 38 days, also find LST and LFT of each job and identify the critical path. Activities: P(1-2) duration 8, no predecessor; Q(1-3) duration 10, no predecessor; R(2-3) duration 12, predecessor P; S(2-4) duration 14, predecessor P; T(3-4) duration 18, predecessors R and Q.
    Topic: Network Analysis: PERT and CPM

    Forward pass (event times): E1 = 0; E2 = 0 + 8 = 8; E3 = max(0 + 10, 8 + 12) = 20; E4 = max(8 + 14, 20 + 18) = 38 days (project duration). Hence: P: EST = 0, EFT = 8. Q: EST = 0, EFT = 10. R: EST = 8, EFT = 20. S: EST = 8, EFT = 22. T: EST = 20, EFT = 38. Backward pass with L4 = 38: L3 = 38 - 18 = 20; L2 = min(20 - 12, 38 - 14) = 8; L1 = min(8 - 8, 20 - 10) = 0. Hence (LST = LFT - duration): P: LFT = 8, LST = 0. Q: LFT = 20, LST = 10. R: LFT = 20, LST = 8. S: LFT = 38, LST = 24. T: LFT = 38, LST = 20. Activities with zero float (EST = LST) are P, R and T, so the critical path is 1-2-3-4 (P-R-T) with length 38 days.

  6. Find the critical path and the expected duration of the project whose network (nodes 1 to 8) has the activities: A(1-2) = 5, B(1-3) = 7, C(2-3) = 11, D(1-4) = 3, E(3-5) = 7, F(4-5) = 9, G(4-6) = 12, H(5-7) = 6, I(5-6) = 5, J(6-8) = 8, K(7-8) = 3 (durations in days).
    Topic: Network Analysis: PERT and CPM

    Enumerate all paths from node 1 to node 8 and add the durations: 1-2-3-5-7-8: A+C+E+H+K = 5+11+7+6+3 = 32. 1-2-3-5-6-8: A+C+E+I+J = 5+11+7+5+8 = 36. 1-3-5-7-8: B+E+H+K = 7+7+6+3 = 23. 1-3-5-6-8: B+E+I+J = 7+7+5+8 = 27. 1-4-5-6-8: D+F+I+J = 3+9+5+8 = 25. 1-4-5-7-8: D+F+H+K = 3+9+6+3 = 21. 1-4-6-8: D+G+J = 3+12+8 = 23. The critical path is the longest path, 1-2-3-5-6-8, i.e. activities A-C-E-I-J, and the expected project duration is 36 days.

  7. If we have 10, 12 and 26 days as the optimistic, most likely and pessimistic times for an activity, calculate (a) the expected time of the activity, (b) the variance and the standard deviation.
    Topic: Network Analysis: PERT and CPM

    (a) Expected time te = (to + 4tm + tp)/6 = (10 + 4(12) + 26)/6 = 84/6 = 14 days. (b) Variance Vt = [(tp - to)/6]^2 = [(26 - 10)/6]^2 = (16/6)^2 = (2.67)^2 = 7.11. Standard deviation = sqrt(Vt) = (tp - to)/6 = 16/6 = 2.67 days.

  8. A teacher notes that when her student starts reading, the optimistic (to), most likely (tm) and pessimistic (tp) time estimates are 10, 20 and 60. Calculate (a) the expected duration of reading, (b) its variance.
    Topic: Network Analysis: PERT and CPM

    (a) Expected time te = (to + 4tm + tp)/6 = (10 + 4(20) + 60)/6 = 150/6 = 25. (b) Variance Vt = [(tp - to)/6]^2 = [(60 - 10)/6]^2 = (50/6)^2 = (8.33)^2 = 69.44.

  9. Discuss the proportionality relation between ordering cost and order quantity. When would the ordering cost per unit item be maximum?
    Topic: Inventory Control

    The ordering (setup) cost per order is fixed, so the ordering cost per unit item is inversely proportional to the quantity ordered: as the order quantity Q increases, the same fixed ordering cost is spread over more units and the ordering cost per unit decreases; as Q decreases, the ordering cost per unit increases. Therefore the ordering cost per unit item is maximum when the ordered quantity is minimum.

  10. Demand rate for a product is 600 units per year. Shortages are not allowed and the holding cost is Rs 0.60 per unit per year. Ordering cost is Rs 80. Find the economic order quantity.
    Topic: Inventory Control

    Here D = 600 units/year, C2 = Rs 80 per order, C3 = Rs 0.60 per unit per year, shortage cost C4 = infinity (shortages not allowed). Wilson's formula: Q* = sqrt(2 C2 D / C3) = sqrt(2 x 80 x 600 / 0.60) = sqrt(160000) = 400 units.

  11. The storage cost of an item is Rs 1 per month and the setup cost is Rs 25 per run. If the production is instantaneous and the demand is 200 units per month, find the optimal size of the batch and the best time for the replacement of inventory.
    Topic: Inventory Control

    Here D = 200 units/month, C3 = Rs 1 per unit per month, C2 = Rs 25 per run, and production is instantaneous (purchasing model without shortages). Optimal batch size Q* = sqrt(2 C2 D / C3) = sqrt(2 x 25 x 200 / 1) = sqrt(10000) = 100 units. Best replacement time (cycle length) t* = Q*/D = 100/200 = 0.5 month, i.e. order 100 units every half month.

  12. Consider the inventory system with the following data: Demand rate = 15000 units/year, item cost = Rs 4/item, ordering cost = Rs 100 per order, holding cost = Rs 0.60 per item per month. Determine (a) the economic order quantity, (b) the time between orders, (c) the number of orders per year.
    Topic: Inventory Control

    Convert the holding cost to a yearly basis: C3 = 0.60 x 12 = Rs 7.20 per item per year. D = 15000, C2 = Rs 100. (a) EOQ = sqrt(2 C2 D / C3) = sqrt(2 x 100 x 15000 / 7.2) = sqrt(416667) = 645.5, i.e. about 645 units. (b) Time between orders = Q*/D = 645.5/15000 = 0.043 year = about 15.7 days. (c) Number of orders per year = D/Q* = 15000/645.5 = about 23.2 orders.

  13. Assume you have a product with the following parameters: Demand = 360 units per year, holding cost = $1.00 per unit per year, order cost = $100 per order. Determine (a) the EOQ, (b) the number of orders per year.
    Topic: Inventory Control

    (a) EOQ = sqrt(2 C2 D / C3) = sqrt(2 x 100 x 360 / 1) = sqrt(72000) = 268.3, i.e. about 268 units. (b) Number of orders per year = D/Q* = 360/268.3 = 1.34 orders per year.

  14. The daily demand of a commodity is 100 units. The holding and ordering costs are Rs 0.02 and Rs 100 respectively. Shortage cost is Rs 5. Determine the economic order quantity (shortages are allowed).
    Topic: Inventory Control

    For the purchasing model with shortages, Q* = sqrt( (2 C2 D / C3) x ((C3 + C4)/C4) ). With D = 100 units/day, C2 = Rs 100, C3 = Rs 0.02, C4 = Rs 5: Q* = sqrt( (2 x 100 x 100 / 0.02) x (5.02/5) ) = sqrt(1000000 x 1.004) = sqrt(1004000) = 1002 units (approx.).

  15. The demand for an item is 15,000 units/year. The cost of one purchase is Rs 400. The holding cost is Rs 1.2 per unit per year. The item cost is Rs 2 per item. The shortage cost is Rs 10 per unit per year. Determine: (a) the optimum order quantity, (b) the time between orders, (c) the number of orders per year, (d) the optimum shortages, (e) the maximum inventory, (f) the optimum total cost.
    Topic: Inventory Control

    D = 15000, C2 = 400, C3 = 1.2, C4 = 10, C1 = 2 (purchasing model with shortages). (a) Q* = sqrt( (2 C2 D / C3) x ((C3 + C4)/C4) ) = sqrt( (2 x 400 x 15000 / 1.2) x (11.2/10) ) = sqrt(11200000) = 3347 units (approx.). (b) Time between orders = Q*/D = 3347/15000 = 0.223 year, i.e. about 2.68 months. (c) Number of orders per year = D/Q* = 15000/3347 = 4.48. (d) Optimum shortage = Q* x C3/(C3 + C4) = 3347 x 1.2/11.2 = 359 units (approx.). (e) Maximum inventory = Q* x C4/(C3 + C4) = 3347 x 10/11.2 = 2988 units (approx.). (f) Minimum variable cost = sqrt( 2 D C2 C3 C4 / (C3 + C4) ) = sqrt(12857143) = Rs 3586 per year; optimum total cost including item cost = C1 D + 3586 = 30000 + 3586 = Rs 33,586 per year.

  16. In a Manufacturing Model with no shortages, Q* = 8490 units, D = 3000 units/month, R = 6000 units/month. Determine (a) the time between orders, (b) the number of orders per year, (c) the time of manufacturing.
    Topic: Inventory Control

    (a) Time between orders (cycle time) t* = Q*/D = 8490/3000 = 2.83 months. (b) Number of orders per year = annual demand / Q* = (3000 x 12)/8490 = 36000/8490 = 4.24 orders per year. (c) Time of manufacturing (production run time) t1 = Q*/R = 8490/6000 = 1.415 months.

  17. Find the optimum manufacturing quantity for the following data of the Manufacturing model with no shortages: Demand = 2500 units/month, Production rate = 5000 units/month, Holding cost = Rs 1 per unit per month, Ordering (setup) cost = Rs 400 per order.
    Topic: Inventory Control

    For the manufacturing model without shortages, Q* = sqrt( 2 C2 D / (C3 (1 - D/R)) ). Here D = 2500, R = 5000, C3 = 1, C2 = 400, so 1 - D/R = 1 - 0.5 = 0.5. Q* = sqrt( 2 x 400 x 2500 / (1 x 0.5) ) = sqrt(4000000) = 2000 units.

  18. The parameters of a production inventory system for automobile pistons are: Demand per year = 6000 units, Unit cost = Rs 40, Setup cost = Rs 500, Holding cost = Rs 8 per unit per year, Production rate = 36000 units per year, Shortage cost = Rs 20 per unit per year. Find (a) the optimum lot size, (b) the number (maximum) of shortages, (c) the manufacturing time and the time between orders. (Manufacturing model with shortages.)

(b) Maximum shortage = Q* x (C3/(C3 + C4)) x (1 - D/R) = 1122 x (8/28) x 0.8333 = 267 units (approx.). (c) Manufacturing time t1 = Q*/R = 1122/36000 year = about 11.4 days.   19. Demand for a product is 600 units per year, and the items are withdrawn at a constant rate. The setup cost for placing an order to replenish inventory is $25. The unit cost of each item is $3, and the inventory holding cost is $0.05 per item per week. (a) Assuming shortages are not allowed, determine how often to make a run and what size it should be. (b) If shortages are allowed but cost $2 per item per month, determine how often to order and what size the order should be.
    Topic: Inventory Control

    Holding cost per item per year C3 = 0.05 x 52 = $2.60. D = 600, C2 = $25. (a) Without shortages: Q* = sqrt(2 C2 D / C3) = sqrt(2 x 25 x 600 / 2.6) = sqrt(11538) = 107.4, i.e. about 107 units per run. Cycle time = Q*/D = 107.4/600 year = 0.179 year = about 9.3 weeks. So order about 107 units every 9.3 weeks. (b) With shortages, C4 = 2 x 12 = $24 per item per year: Q* = sqrt( (2 C2 D / C3) x ((C3 + C4)/C4) ) = sqrt(11538 x 26.6/24) = sqrt(12788) = 113.1, i.e. about 113 units per order. Maximum inventory = Q* x C4/(C3 + C4) = 113.1 x 24/26.6 = 102 units. Cycle time = 113.1/600 year = about 9.8 weeks. So order about 113 units every 9.8 weeks.

  20. The demand for a purchased item is 2000 units per month and shortages are allowed. The unit cost is Rs 20 per unit, the cost of making one purchase is Rs 1000, the holding cost for 1 unit is Rs 20 per year and the cost of one shortage is Rs 500 per year. (a) Q* = sqrt( (2 C2 D / C3) x ((C3 + C4)/C4) ) = sqrt( (2 x 1000 x 24000 / 20) x (520/500) ) = sqrt(2496000) = 1580 units (approx.). (b) Time between orders = Q*/D = 1580/24000 year = about 24 days. (c) Number of orders per year = D/Q* = 24000/1580 = 15.19. (d) Optimum shortage = Q* x C3/(C3 + C4) = 1580 x 20/520 = 61 units (approx.).   21. A company produces 36000 units per year and the demand of the product is 2400 items per year.   23. Write short notes on Economic Order Quantity and Dynamic Order Quantity.
    Topic: Inventory Control

    Economic Order Quantity (EOQ): The order quantity which minimizes the total inventory cost, obtained by balancing the ordering (setup) cost against the carrying (holding) cost. The basic EOQ models assume uniform (constant) demand, a fixed setup cost per order and a holding cost per unit per unit time; e.g. for the purchasing model without shortages, Q* = sqrt(2 C2 D / C3). Dynamic Order Quantity: When the demand is not uniform but varies from period to period (seasonal or irregular), the EOQ assumption fails. In the dynamic order quantity model, the requirements of succeeding months are combined with a preceding month whenever the saving in setup (procurement) cost outweighs the additional carrying cost of holding the items; the procedure is continued until the procurement and carrying costs are balanced. This gives an economical ordering plan for varying demand.

  24. Rabbani and Sons of Sialkot manufacture sports goods like hockey sticks and cricket bats. Each hockey stick yields a profit of Rs 20 and each cricket bat Rs 25. A hockey stick requires four hours of processing at machine A and two hours at machine B. A bat requires six hours of processing at machine A, five hours at machine B and one hour at machine C. Machine A has a maximum of 135 hours available, machine B has 75 hours and machine C has 20 hours. Formulate the problem as an LP model to maximize the company's profit.
    Topic: Linear Programming and Simplex Method

    Decision variables: x1 = number of hockey sticks produced, x2 = number of cricket bats produced. Objective function: since each hockey stick yields a profit of Rs 20 and each cricket bat Rs 25, maximize Z = 20x1 + 25x2. Constraints (machine hours): Machine A: 4x1 + 6x2 <= 135. Machine B: 2x1 + 5x2 <= 75. Machine C: 0x1 + 1x2 <= 20. Non-negativity: x1, x2 >= 0. Hence the LP model is: Maximize Z = 20x1 + 25x2 subject to 4x1 + 6x2 <= 135, 2x1 + 5x2 <= 75, x2 <= 20, x1, x2 >= 0.

  25. A home decorator manufactures two types of lamps, A and B. Both lamps go through two technicians, first a cutter and second a finisher. Lamp A requires 2 hours of the cutter's time and 1 hour of the finisher's time. Lamp B requires 1 hour of the cutter's time and 2 hours of the finisher's time. The cutter has 104 hours and the finisher has 76 hours of available time each month. Profit on one lamp A is Rs 6.00 and on one lamp B is Rs 11.00. Formulate the above as a linear programming model.
    Topic: Linear Programming and Simplex Method

    Decision variables: x = number of lamps A produced per month, y = number of lamps B produced per month. Objective function: Maximize Z = 6x + 11y. Constraints: Cutter time: 2x + y <= 104. Finisher time: x + 2y <= 76. Non-negativity: x, y >= 0.

  26. An animal feed manufacturer has to produce 200 kg of a feed mixture consisting of two ingredients X1 and X2. X1 costs Rs 6 per kg while X2 costs Rs 16 per kg. Not more than 80 kg of X1 and not less than 60 kg of X2 can be used. Formulate the above as a linear programming model.
    Topic: Linear Programming and Simplex Method

    Decision variables: x1 = quantity (kg) of ingredient X1 in the mixture, x2 = quantity (kg) of ingredient X2 in the mixture. Objective function (minimize cost): Minimize Z = 6x1 + 16x2. Constraints: Total mixture: x1 + x2 = 200. Limit on X1: x1 <= 80. Limit on X2: x2 >= 60. Non-negativity: x1, x2 >= 0.

  27. Solve the following problem using the simplex method: Maximize Z = 9x1 + 8x2 + 7x3 subject to 2x1 + x2 + 2x3 <= 50, x1 + 3x2 + x3 <= 25, x1 + 2x2 + x3 <= 26, x1, x2, x3 >= 0.
    Topic: Linear Programming and Simplex Method

    Introduce slack variables s1, s2, s3. The initial basic feasible solution is x1 = x2 = x3 = 0, s1 = 50, s2 = 25, s3 = 26, with Z = 0. Iteration 1: the entering variable is x1 (largest coefficient, 9). Minimum ratio test: min(50/2, 25/1, 26/1) = 25 (tie between the first two rows); pivoting on the first row, s1 leaves and x1 = 25 enters the basis. This gives the basic feasible solution x1 = 25, x2 = 0, x3 = 0 (with s2 = 0, s3 = 1), and Z = 9(25) = 225. Optimality check: all coefficients in the objective row are non-negative (the reduced cost of x2 is zero, showing degeneracy), so the solution is optimal. Optimal solution: x1 = 25, x2 = 0, x3 = 0, with maximum Z = 225. Verification: 2(25) + 0 + 0 = 50 <= 50; 25 + 0 + 0 = 25 <= 25; 25 + 0 + 0 = 25 <= 26.
