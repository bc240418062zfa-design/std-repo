  1. Express the differential equation k(y^2 + dy/dx) = y - x dy/dx into separable form.
    Topic: Separable Equations

    Expanding, k y^2 + k dy/dx = y - x dy/dx. Collecting the derivative terms: (k + x) dy/dx = y - k y^2 = y(1 - k y). Hence the separable form is: dy / [y(1 - k y)] = dx / (x + k).

  2. Express the differential equation x^2 - y dy/dx = e^x into separable form. Also find its constant solution.
    Topic: Separable Equations

    Rearranging: y dy/dx = x^2 - e^x, so the separable form is y dy = (x^2 - e^x) dx. For a constant solution y = c we need dy/dx = 0, which gives x^2 = e^x for all x. This is impossible, so the equation has no constant solution.

  3. Solve the differential equation ln(dy/dx) = y.
    Topic: Separable Equations

    ln(dy/dx) = y gives dy/dx = e^y. Separating the variables: e^(-y) dy = dx. Integrating: -e^(-y) = x + C, so e^(-y) = C1 - x and the solution is y = -ln(C1 - x).

  4. Transform the homogeneous differential equation y(y dx - x dy) + x sqrt(x^2 + y^2) dy = 0 into separable form by using the substitution y = v x.
    Topic: Homogeneous Equations and Substitutions

    The equation gives dy/dx = y^2 / (x y - x sqrt(x^2 + y^2)). Dividing numerator and denominator by x^2 and putting y = v x: dy/dx = v^2 / (v - sqrt(1 + v^2)). Since dy/dx = v + x dv/dx, we get x dv/dx = v sqrt(1 + v^2) / (v - sqrt(1 + v^2)), which separates into the form: [1 / sqrt(1 + v^2) - 1/v] dv = dx / x.

  5. Determine whether the following function is homogeneous or not. If it is homogeneous, also give its degree: f(x, y) = 1/y.
    Topic: Homogeneous Equations and Substitutions

    f(t x, t y) = 1/(t y) = t^(-1) . (1/y) = t^(-1) f(x, y). Hence f(x, y) = 1/y is a homogeneous function, of degree -1.

  6. Determine whether the differential equation (y cos x + 2x e^y) dx + (sin x + x^2 e^y - 1) dy = 0 is exact or not. If exact, solve it.
    Topic: Exact Equations and Integrating Factors

    Here M = y cos x + 2x e^y and N = sin x + x^2 e^y - 1. ∂M/∂y = cos x + 2x e^y and ∂N/∂x = cos x + 2x e^y, which are equal, so the equation is exact. Integrating M with respect to x: F(x, y) = y sin x + x^2 e^y + h(y). Then ∂F/∂y = sin x + x^2 e^y + h'(y) = N gives h'(y) = -1, so h(y) = -y. The solution is: y sin x + x^2 e^y - y = C.

  7. Determine whether e^x is an integrating factor for the non-exact differential equation y(x + y + 1) dx + (x + 2y) dy = 0.
    Topic: Exact Equations and Integrating Factors

    Multiplying the equation by e^x gives M1 = e^x y (x + y + 1) and N1 = e^x (x + 2y). Now ∂M1/∂y = e^x (x + 2y + 1) and ∂N1/∂x = e^x (x + 2y) + e^x = e^x (x + 2y + 1). Since ∂M1/∂y = ∂N1/∂x, the multiplied equation is exact. Hence, yes, e^x is an integrating factor of the given equation.

  8. Determine the particular solution of the initial value problem: x cos x dx + (1 + 6y^5) dy = 0, y(pi) = 0.
    Topic: Exact Equations and Integrating Factors

    Integrating term by term: ∫ x cos x dx = x sin x + cos x and ∫ (1 + 6y^5) dy = y + y^6, so the general solution is x sin x + cos x + y + y^6 = C. Applying y(pi) = 0: pi sin pi + cos pi + 0 + 0 = -1 = C. Hence the particular solution is: x sin x + cos x + y + y^6 = -1.

  9. Discuss the exactness of the differential equation (sin y - y sin x) dx + (cos x + x cos y) dy = 0 and solve it.
    Topic: Exact Equations and Integrating Factors

    Here M = sin y - y sin x and N = cos x + x cos y. ∂M/∂y = cos y - sin x and ∂N/∂x = -sin x + cos y, which are equal, so the equation is exact. Integrating M with respect to x: F(x, y) = x sin y + y cos x + h(y). Then ∂F/∂y = x cos y + cos x + h'(y) = N gives h'(y) = 0. The solution is: x sin y + y cos x = C.

  10. Convert the differential equation (x + 2y^3) dy/dx = y into standard linear form.
    Topic: First Order Linear and Bernoulli Equations

    Writing the equation with x as the dependent variable: dx/dy = (x + 2y^3)/y = (1/y) x + 2y^2. Hence the standard linear form is: dx/dy - (1/y) x = 2y^2.

  11. Solve the differential equation (1 + x^2) dy/dx + y = tan^(-1) x.
    Topic: First Order Linear and Bernoulli Equations

    Dividing by (1 + x^2): dy/dx + y/(1 + x^2) = tan^(-1) x / (1 + x^2). The integrating factor is mu = e^(∫ dx/(1 + x^2)) = e^(tan^(-1) x). Hence y e^(tan^(-1) x) = ∫ e^(tan^(-1) x) tan^(-1) x / (1 + x^2) dx. Substituting u = tan^(-1) x, du = dx/(1 + x^2), the integral becomes ∫ u e^u du = e^u (u - 1) + C. Therefore the solution is: y = tan^(-1) x - 1 + C e^(-tan^(-1) x).

  12. Using a suitable substitution, reduce the Bernoulli differential equation x dy/dx + y = y^2 log x into a linear first order differential equation.
    Topic: First Order Linear and Bernoulli Equations

    Dividing by x, the standard Bernoulli form is dy/dx + (1/x) y = ((log x)/x) y^2, with n = 2. Use the substitution v = y^(1 - n) = y^(-1), so dv/dx = -y^(-2) dy/dx. Dividing the equation by y^2 and substituting gives -dv/dx + (1/x) v = (log x)/x, i.e. the linear equation: dv/dx - (1/x) v = -(log x)/x.

  13. Solve the differential equation dy/dx + x sin 2y = x^3 cos^2 y.
    Topic: First Order Linear and Bernoulli Equations

    Dividing both sides by cos^2 y: sec^2 y dy/dx + 2x tan y = x^3. Substituting v = tan y, dv/dx = sec^2 y dy/dx, gives the linear equation dv/dx + 2x v = x^3, whose integrating factor is e^(x^2). Then v e^(x^2) = ∫ x^3 e^(x^2) dx = (1/2)(x^2 - 1) e^(x^2) + C. Hence the solution is: tan y = (x^2 - 1)/2 + C e^(-x^2).

  14. Convert the differential equation dy/dx (x^2 y^3 + x y) = 1 into linear form.
    Topic: First Order Linear and Bernoulli Equations

    Inverting: dx/dy = x^2 y^3 + x y, i.e. dx/dy - y x = y^3 x^2, which is a Bernoulli equation in x with n = 2. Substituting v = x^(-1), so dv/dy = -x^(-2) dx/dy, and dividing by x^2 gives the linear equation: dv/dy + y v = -y^3.

  15. What is the Logistic equation? Write it mathematically.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    The logistic equation is the differential equation used to model population growth when the environment can support only a limited maximum population (the carrying capacity): dP/dt = P(a - bP), where a, b > 0 are constants, P(t) is the population at time t, a is the intrinsic growth rate and a/b is the carrying capacity. Its constant (equilibrium) solutions are P = 0 and P = a/b.

  16. In which sciences or subjects are Logistic equations useful?
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Logistic equations are useful in biology and ecology (growth of populations of organisms), epidemiology (the spread of infectious diseases), medicine, chemistry (autocatalytic reactions), and in economics and marketing (the diffusion of new products and technologies).

  17. Deduce the special case of the Logistic equation: 'Epidemic spread'.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Consider a fixed population of N people, of which P(t) are infected and Q(t) = N - P(t) are uninfected at time t. The disease spreads through contact between infected and uninfected persons, so its rate of spread is proportional to the product P Q: dP/dt = k P Q = k P (N - P) = k N P (1 - P/N). This is exactly the logistic equation dP/dt = P(a - bP) with a = k N and b = k. Hence epidemic spread is a special case of the logistic equation.

  18. Find the differential equation of the orthogonal family of curves y = c x^2, where c is an arbitrary constant.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Differentiating: dy/dx = 2 c x. Eliminating c = y/x^2 gives the differential equation of the family: dy/dx = 2y/x. For the orthogonal trajectories the slope is replaced by its negative reciprocal, -x/(2y), so the orthogonal family satisfies dy/dx = -x/(2y), i.e. 2y dy + x dx = 0, which integrates to x^2 + 2y^2 = C.

  19. Find the orthogonal trajectory to the family of curves a y^2 = x^3.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Differentiating a y^2 = x^3: 2a y dy/dx = 3x^2, so dy/dx = 3x^2/(2a y). Using a = x^3/y^2 this becomes dy/dx = 3y/(2x). For the orthogonal trajectories, dy/dx = -2x/(3y), i.e. 3y dy + 2x dx = 0. Integrating: 2x^2 + 3y^2 = C, a family of ellipses.

  20. Find the slope of the line orthogonal to the curve y = e^x cosh x at the point (0, 1).
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Since e^x cosh x = (e^(2x) + 1)/2, we have y = (e^(2x) + 1)/2 and dy/dx = e^(2x). At x = 0 the slope of the tangent is e^0 = 1. The line orthogonal to the curve (the normal) therefore has slope -1/1 = -1.

  21. Find the differential equation satisfied by the family of curves y = sin x + k cos x, where k is an arbitrary constant.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Differentiating: dy/dx = cos x - k sin x. From the given family, k = (y - sin x)/cos x. Substituting this value of k: cos x dy/dx = cos^2 x - y sin x + sin^2 x = 1 - y sin x. Hence the required differential equation is: cos x dy/dx + y sin x = 1.

  22. Using Newton's Law of Cooling with initial condition T(0) = T0, and if temperatures at times t1 and t2 are known, then show that (T(t1) - Tm) / (T(t2) - Tm) = e^(k(t1 - t2)), where Tm is the temperature of the surrounding medium.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Newton's Law of Cooling gives the initial value problem dT/dt = k(T - Tm), T(0) = T0. The equation is linear as well as separable. Separating the variables and integrating: ∫ dT/(T - Tm) = ∫ k dt, so ln |T - Tm| = k t + C and T(t) = Tm + C1 e^(k t). The initial condition T(0) = T0 gives C1 = T0 - Tm, hence T(t) = Tm + (T0 - Tm) e^(k t). Therefore T(t1) - Tm = (T0 - Tm) e^(k t1) and T(t2) - Tm = (T0 - Tm) e^(k t2). Dividing the two expressions, (T(t1) - Tm) / (T(t2) - Tm) = e^(k t1) / e^(k t2) = e^(k(t1 - t2)), as required.

  23. If the half-life (T) of a radioactive isotope is 5 days, then find k.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    By definition of half-life, A(T) = A0/2. From A(t) = A0 e^(k t): A0/2 = A0 e^(5 k), so e^(5k) = 1/2 and k = -(ln 2)/5 = -0.6931/5 ≈ -0.1386 per day. (The negative sign shows that the amount is decreasing.)

  24. A radioactive isotope has a half-life of 16 days. We have 45 g at the end of 32 days. How much of the radioisotope was initially present?
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Using A(t) = A0 (1/2)^(t/16): 45 = A0 (1/2)^(32/16) = A0 (1/2)^2 = A0/4. Hence A0 = 4 × 45 = 180 g.

  25. The half-life of a radioactive substance is 16 days. If the amount of the substance remaining after 30 days is 30 g, then find the initial amount of the substance.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    With half-life 16 days, k = -(ln 2)/16 and A(t) = A0 e^(k t). Putting A(30) = 30: 30 = A0 e^(-(ln 2)(30/16)) = A0 (1/2)^(30/16), so A0 = 30 × 2^(30/16) = 30 × 2^(1.875) ≈ 30 × 3.668 ≈ 110.04 g.

  26. If the population P(t) of a community is growing according to P(t) = P0 e^(0.0534 t), then how long will it take to become four times the initial population?
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    Setting P(t) = 4 P0: 4 P0 = P0 e^(0.0534 t), so e^(0.0534 t) = 4 and t = (ln 4)/0.0534 = 1.3863/0.0534 ≈ 25.96 years, i.e. about 26 years.

  27. If a mass weighing 20 lb stretches a spring by 1/2 ft, then find k using Hooke's Law.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    By Hooke's Law, F = k s, where the force equals the weight: k = W/s = 20 / (1/2) = 40 lb/ft.

  28. If a weight of 15 lb stretches a spring 3 ft, then find the value of k in Hooke's Law.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    By Hooke's Law, k = W/s = 15/3 = 5 lb/ft.

  29. If a mass weighing 8 lb is attached to a spring with spring constant k = 40 lb/ft, then find the amount of elongation 's'.
    Topic: Applications: Orthogonal Trajectories, Growth, Decay and Logistic Model

    By Hooke's Law, W = k s, so s = W/k = 8/40 = 0.2 ft.

  30. State the superposition principle for linear differential equations.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    If y1 and y2 are two solutions of a homogeneous linear differential equation on an interval I, then any linear combination c1 y1 + c2 y2 (with constants c1, c2) is also a solution of the equation on I. This superposition principle is a property of linear differential equations only; it does not hold for nonlinear differential equations.

  31. How is the general solution of a non-homogeneous linear differential equation expressed in terms of its complementary and particular solutions?
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    The general solution is y = y_c + y_p, where y_c, the complementary function, is the general solution of the associated homogeneous equation and contains all the arbitrary constants, while y_p is any one particular solution of the non-homogeneous equation.

  32. Show that y = x^2 is a solution of the differential equation x^2 d2y/dx2 - 3x dy/dx + 4y = 0.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    For y = x^2: dy/dx = 2x and d2y/dx2 = 2. Substituting in the left-hand side: x^2 (2) - 3x (2x) + 4 (x^2) = 2x^2 - 6x^2 + 4x^2 = 0, which equals the right-hand side. Hence y = x^2 is a solution of the equation.

  33. Given that y = c1 e^x + c2 e^(-x) is a two-parameter family of solutions of the differential equation d2y/dx2 - y = 0 on (-infinity, infinity), find a member of the family satisfying the boundary conditions y(0) = 0, y'(1) = 1.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    y(0) = c1 + c2 = 0 gives c2 = -c1. Now y' = c1 e^x - c2 e^(-x), so y'(1) = c1 e + c1 e^(-1) = c1 (e + 1/e) = 1, giving c1 = 1/(e + e^(-1)) = e/(e^2 + 1) ≈ 0.324 and c2 ≈ -0.324. Hence the required member of the family is y = [e/(e^2 + 1)] (e^x - e^(-x)).

  34. Find the Wronskian of the differential equation y''' - 2y'' - 21y' - 18y = 3 + 4e^(-x) using variation of parameters, where the roots of the auxiliary equation are m1 = -3, m2 = -1, m3 = 6.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    The complementary solutions are y1 = e^(-3x), y2 = e^(-x), y3 = e^(6x). Their Wronskian is the determinant of the matrix with rows (y1, y2, y3), (y1', y2', y3'), (y1'', y2'', y3''). Factoring e^(-3x), e^(-x) and e^(6x) from the three columns gives W = e^(2x) × det [[1, 1, 1], [-3, -1, 6], [9, 1, 36]] = e^(2x) × [(-36 - 6) - (-108 - 54) + (-3 + 9)] = e^(2x) × (-42 + 162 + 6) = 126 e^(2x).

  35. Calculate the Wronskian of the functions f1(x) = sin^2 x and f2(x) = cos^2 x. Further determine whether they are linearly independent or not on the interval (-infinity, infinity).
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    f1'(x) = 2 sin x cos x and f2'(x) = -2 sin x cos x. Hence W(f1, f2) = f1 f2' - f2 f1' = sin^2 x (-2 sin x cos x) - cos^2 x (2 sin x cos x) = -2 sin x cos x (sin^2 x + cos^2 x) = -2 sin x cos x = -sin 2x. Since the Wronskian is not identically zero on (-infinity, infinity), the functions are linearly independent.

  36. Show that the functions f1(x) = sin x and f2(x) = x are linearly independent.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    W(f1, f2) = | sin x, x ; cos x, 1 | = sin x (1) - x cos x = sin x - x cos x. This is not identically zero on any interval (for example, at x = pi/2 its value is 1). Hence f1(x) = sin x and f2(x) = x are linearly independent.

  37. If y1(x) = e^x is the first solution of d2y/dx2 + 2 dy/dx - 3y = 0, then construct its second solution using y2(x) = y1(x) ∫ (e^(-∫P(x) dx) / y1^2(x)) dx.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    Here P(x) = 2, so e^(-∫P(x) dx) = e^(-2x). Then y2 = e^x ∫ e^(-2x) / e^(2x) dx = e^x ∫ e^(-4x) dx = e^x . (-1/4) e^(-4x) = -(1/4) e^(-3x). Dropping the constant multiple, the second solution is y2(x) = e^(-3x).

  38. If y1(x) = e^(-4x) is the first solution of d2y/dx2 + 6 dy/dx + 8y = 0, then construct its second solution using y2(x) = y1(x) ∫ (e^(-∫P(x) dx) / y1^2(x)) dx.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    Here P(x) = 6, so e^(-∫P(x) dx) = e^(-6x). Then y2 = e^(-4x) ∫ e^(-6x) / e^(-8x) dx = e^(-4x) ∫ e^(2x) dx = e^(-4x) . (1/2) e^(2x) = (1/2) e^(-2x). Dropping the constant multiple, the second solution is y2(x) = e^(-2x).

  39. Solve the boundary value problem d2y/dx2 + 25y = 0 subject to the boundary conditions y(0) = 0, y(pi/10) = 0.
    Topic: Higher Order Linear Equations: Independence and the Wronskian

    The general solution is y = c1 cos 5x + c2 sin 5x. The condition y(0) = 0 gives c1 = 0. The condition y(pi/10) = 0 gives c2 sin(pi/2) = c2 = 0. Hence c1 = c2 = 0, and the boundary value problem has only the trivial solution y = 0.

  40. What is meant by the auxiliary (characteristic) equation of a homogeneous linear differential equation with constant coefficients? Find the characteristic equation and its roots for d2y/dx2 - 9y = 0.
    Topic: Homogeneous Equations with Constant Coefficients

    The auxiliary equation is the algebraic equation obtained by replacing each derivative d^k y/dx^k in the differential equation by m^k (equivalently, by substituting the trial solution y = e^(m x)). For d2y/dx2 - 9y = 0 the auxiliary equation is m^2 - 9 = 0, whose roots are m = 3 and m = -3.

  41. Factorize D^4 - 8D^2 + 16 and hence write down the general solution of (D^4 - 8D^2 + 16) y = 0.
    Topic: Homogeneous Equations with Constant Coefficients

    D^4 - 8D^2 + 16 = (D^2 - 4)^2 = (D - 2)^2 (D + 2)^2. The roots of the auxiliary equation are m = 2 (repeated) and m = -2 (repeated). Hence the general solution is y = (c1 + c2 x) e^(2x) + (c3 + c4 x) e^(-2x).

  42. If L = D^2 - 5D - 6 is a linear differential operator such that L y = 0, then construct the differential equation corresponding to L and find its general solution.
    Topic: Homogeneous Equations with Constant Coefficients

    The corresponding differential equation is d2y/dx2 - 5 dy/dx - 6y = 0. Its auxiliary equation m^2 - 5m - 6 = 0 factorizes as (m - 6)(m + 1) = 0, giving roots m = 6 and m = -1. Hence the general solution is y = c1 e^(6x) + c2 e^(-x).

  43. Write the following differential equation in the form L(y) = g(x), where L is a linear differential operator with constant coefficients: d2y/dx2 - 2 dy/dx + 5y = 2 sin y.
    Topic: Homogeneous Equations with Constant Coefficients

    Taking L = D^2 - 2D + 5, we have L(y) = (D^2 - 2D + 5) y = d2y/dx2 - 2 dy/dx + 5y, and g(x) = 2 sin y. Hence the equation is written as L(y) = g(x) with L = D^2 - 2D + 5.

  44. Find the general solution of the following non-homogeneous differential equation using the annihilator operator: y'' - 3y' + 2y = 4x^2 + 5.
    Topic: Undetermined Coefficients and the Annihilator Operator

    The auxiliary equation m^2 - 3m + 2 = 0 gives m = 1, 2, so y_c = c1 e^x + c2 e^(2x). The annihilator of 4x^2 + 5 is D^3, so take the trial solution y_p = A x^2 + B x + C. Substituting in the equation: 2A x^2 + (2B - 6A) x + (2A - 3B + 2C) = 4x^2 + 5. Comparing coefficients: 2A = 4 gives A = 2; 2B - 6A = 0 gives B = 6; 2A - 3B + 2C = 5 gives 4 - 18 + 2C = 5, so C = 19/2. Hence y_p = 2x^2 + 6x + 19/2 and the general solution is y = c1 e^x + c2 e^(2x) + 2x^2 + 6x + 19/2.

  45. Find the order of the homogeneous equation obtained from the following non-homogeneous differential equation: y'' + 4y' + 3y = 4x^2 + 5.
    Topic: Undetermined Coefficients and the Annihilator Operator

    The right-hand side 4x^2 + 5 is a polynomial of degree 2, which is annihilated by D^3. Applying D^3 to both sides gives D^3 (D^2 + 4D + 3) y = 0, a homogeneous linear differential equation of order 3 + 2 = 5. Hence the required order is 5.

  46. Determine the annihilator operator of the general solution of the homogeneous linear first order differential equation dy/dx - 5y = 0.
    Topic: Undetermined Coefficients and the Annihilator Operator

    The general solution of dy/dx - 5y = 0 is y = c e^(5x). The operator (D - 5) annihilates e^(5x), since (D - 5) e^(5x) = 5 e^(5x) - 5 e^(5x) = 0. Hence the annihilator operator is (D - 5).

  47. If the complementary solution of the differential equation d2y/dx2 + 4y = cos 2x is c1 sin 2x + c2 cos 2x, then what will be the general form of its particular solution?
    Topic: Undetermined Coefficients and the Annihilator Operator

    Since cos 2x (and sin 2x) already occur in the complementary solution, the usual trial A cos 2x + B sin 2x must be multiplied by x. Hence the general form of the particular solution is y_p = x (A cos 2x + B sin 2x).

  48. What will be the general form of the particular solution of the differential equation d2y/dx2 - 2 dy/dx + y = e^x?
    Topic: Undetermined Coefficients and the Annihilator Operator

    The auxiliary equation (m - 1)^2 = 0 has the repeated root m = 1, so both e^x and x e^x occur in the complementary solution. The trial solution must therefore be multiplied by x^2, giving the general form y_p = A x^2 e^x.

  49. Given L = D^2 + 5D + 6 is a linear differential operator. Then: 1. Factorise L. 2. Verify that L annihilates the general solution of d2y/dx2 + 5 dy/dx + 6y = 0.
    Topic: Undetermined Coefficients and the Annihilator Operator

    1. L = D^2 + 5D + 6 = (D + 2)(D + 3). 2. The auxiliary equation m^2 + 5m + 6 = 0 gives m = -2, -3, so the general solution is y = c1 e^(-2x) + c2 e^(-3x). Now (D + 3) e^(-2x) = e^(-2x) and then (D + 2) e^(-2x) = 0, so L e^(-2x) = 0. Similarly (D + 2) e^(-3x) = -e^(-3x) and then (D + 3)(-e^(-3x)) = 0, so L e^(-3x) = 0. Hence L annihilates every member of the general solution, i.e. L annihilates the general solution.

  50. Determine the annihilator operator of p x sin(q x), where p, q are real numbers.
    Topic: Undetermined Coefficients and the Annihilator Operator

    The function x sin(q x) is a product of x with sin(q x). Since (D^2 + q^2) annihilates sin(q x) and cos(q x), and multiplication by x requires the operator to be applied twice, the annihilator of p x sin(q x) is (D^2 + q^2)^2.

  51. If the complementary solution of y'' + 3y' + 2y = e^x sin(2x + 3) is y_c = a e^(-x) + b e^(-2x), then determine the form of its particular solution.
    Topic: Undetermined Coefficients and the Annihilator Operator

    e^x sin(2x + 3) is a linear combination of e^x cos 2x and e^x sin 2x. Since 1 + 2i and 1 - 2i are not roots of the auxiliary equation m^2 + 3m + 2 = 0, no modification is needed, and the form of the particular solution is y_p = e^x (A cos 2x + B sin 2x).

  52. If m^3 + a m = 0 is an associated auxiliary equation of the differential equation d3y/dx3 + a dy/dx = 0, a > 0, then find its general solution.
    Topic: Undetermined Coefficients and the Annihilator Operator

    Factorising: m (m^2 + a) = 0, so the roots are m = 0 and m = ± i sqrt(a). Hence the general solution is y = c1 + c2 cos(sqrt(a) x) + c3 sin(sqrt(a) x).

  53. Evaluate e^(-∫P(x) dx) using the differential equation x^2 d2y/dx2 + x dy/dx + (x^2 - 1/4) y = 0 by writing it in the standard form d2y/dx2 + P(x) dy/dx + Q(x) y = 0.
    Topic: Variation of Parameters

    Dividing by x^2, the standard form is d2y/dx2 + (1/x) dy/dx + (1 - 1/(4x^2)) y = 0, so P(x) = 1/x. Therefore e^(-∫P(x) dx) = e^(-∫ (1/x) dx) = e^(-ln x) = 1/x.

  54. Define the cycle of a vibrating body.
    Topic: Simple Harmonic Motion

    A cycle of a vibrating body is one complete vibration: the motion of the body from a particular position, through its full oscillation, back to the same position while moving in the same direction. The time taken to complete one cycle is called the period of the motion.

  55. Write the solution x(t) = c1 cos w t + c2 sin w t of a simple harmonic motion in a simple alternative form.
    Topic: Simple Harmonic Motion

    The solution can be written as a single sine function: x(t) = A sin(w t + phi), where A = sqrt(c1^2 + c2^2) is the amplitude of the motion and phi = tan^(-1)(c1/c2) is the phase angle. (Equivalently, x(t) = A cos(w t - delta) with delta = tan^(-1)(c2/c1).)

  56. Find the period of vibration of the solution of a simple harmonic motion.
    Topic: Simple Harmonic Motion

    For the solution x(t) = A sin(w t + phi), the motion repeats itself when the argument increases by 2 pi, i.e. when w T = 2 pi. Hence the period of vibration is T = 2 pi / w, and the frequency (number of cycles per unit time) is f = 1/T = w / (2 pi).

  57. If the position x at any time t, for a body performing simple harmonic motion, is x(t) = cos(t/2) + sqrt(3) sin(t/2), then find its amplitude.
    Topic: Simple Harmonic Motion

    Comparing with x(t) = c1 cos w t + c2 sin w t, the amplitude is A = sqrt(c1^2 + c2^2) = sqrt(1^2 + (sqrt(3))^2) = sqrt(1 + 3) = 2. (Indeed, x(t) = 2 cos(t/2 - pi/3).)

  58. A mass weighing 2 lb stretches a spring 6 inches. Determine the equation of simple harmonic motion.
    Topic: Simple Harmonic Motion

    The stretch is s = 6 inches = 1/2 ft, so by Hooke's Law k = W/s = 2 / (1/2) = 4 lb/ft. The mass is m = W/g = 2/32 = 1/16 slug. Newton's second law gives m d2x/dt2 = -k x, i.e. (1/16) d2x/dt2 + 4x = 0, or d2x/dt2 + 64 x = 0. Its solution, the equation of the simple harmonic motion, is x(t) = c1 cos 8t + c2 sin 8t.

  59. Determine the equation of simple harmonic motion for a mass weighing W lb, which stretches a spring by s feet.
    Topic: Simple Harmonic Motion

    By Hooke's Law the spring constant is k = W/s, and the mass is m = W/g. When the mass is displaced by x from equilibrium, Newton's second law gives m d2x/dt2 = -k x, i.e. d2x/dt2 + (k/m) x = 0. Since k/m = (W/s) / (W/g) = g/s, the equation of simple harmonic motion is d2x/dt2 + (g/s) x = 0, with angular frequency w = sqrt(g/s).
