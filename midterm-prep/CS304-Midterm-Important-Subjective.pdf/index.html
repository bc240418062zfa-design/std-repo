  4. Explain two benefits of setter functions. (Marks: 2)

  8. Write three important properties of constructors. Also tell the reason why we cannot overload the following four operators in C++: . , .* , :: , ?: — and, considering the Complex number class, can we subtract two complex numbers by overloading the plus '+' operator? Justify your answer.

  9. Can we create an array of objects for a class having user defined constructor? Justify your answer. (Marks: 2)
    Topic: Constructors, Object Arrays & Initialization Order

    No — not with a user defined (parameterized) constructor alone. When an array of objects is created, every element has to be constructed without arguments, so there must always be a default constructor if we want to create an array of objects. If the class provides only a user defined constructor, an array of objects cannot be created unless a default constructor is also defined.

  10. Can we create an array of objects for a class having default constructor? Justify your answer. (Marks: 2)
    Topic: Constructors, Object Arrays & Initialization Order

    Yes. When an array of objects is created, the constructor is called for each element of the array. Since no arguments can be supplied while creating an array, the default constructor (the constructor with no parameters) is invoked for every element. Therefore, if a class has a default constructor, an array of its objects can be created, and each element is initialized by that default constructor.

  12. Consider the class given below. What will be the values in variables x, y and z after creating an object of this class? (Marks: 3)
    Topic: Constructors, Object Arrays & Initialization Order

    class ABC { int x; int y; int z; public: ABC(); }; ABC::ABC() : x(10), z(x), y(x) { ... } Variables are initialized in the order of their declaration in the class (x, y, z), regardless of the order in the initializer list. So x is initialized first with 10; then y is initialized with the value of x, i.e. 10; then z is initialized with the value of x, i.e. 10. x = 10, y = 10 and z = 10.

  13. What are static data members? (Marks: 2)

  14. Explain the difference between the static variable of a class and the non-static variable, with the help of an example.
    Topic: Static Members

    The difference between static and non-static members is only that a non-static member is tied to an instance of a class, whereas a static member is tied to the class and not to a particular instance. That is, a static member is shared by all instances of a class, although a non-static member exists separately for each instance of the class. Example: in a Student class, rollNo is a non-static member — every student object has its own rollNo. A static member such as a counter of students is shared by all objects, so increasing it through any one object is visible to all objects of the class.

  29. Give at least two problems that we should check when we are overloading the assignment operator ("=") in the String class.
    Topic: Assignment Operator, Copying & Special Operators

    1. Self-assignment (self-referencing): an object may be assigned to itself, e.g. str = str; The overloaded assignment operator must check for this case, otherwise it would first delete its own buffer and then try to copy data from the already-freed memory, corrupting the object. 2. Chained (cascaded) assignment: assignments in a single line such as stringObject1 = stringObject2 = stringObject3 = stringObject4 must work. For this, the assignment operator must return a reference to the assigned object (String &) so that the result of one assignment can be used as the operand of the next. (Related: the old memory of the destination object must also be released properly, otherwise memory leakage and dangling pointers occur.)

  30. How do we resolve the following problems in overloading of the assignment operator in the String class? Explain with the help of C++ code. (i) Self referencing. (ii) Assigning a string value to more than one string in a single line, like stringObject1 = stringObject2 = stringObject3 = stringObject4.
    Topic: Assignment Operator, Copying & Special Operators

    Both problems are resolved by defining the assignment operator to return a reference to the object itself (String &) and by guarding against self-assignment before releasing the old buffer: class String { ... public: ... String & operator = (const String &); }; String & String::operator = (const String & rhs) { if (this != &rhs) { // protects against self-assignment size = rhs.size; delete [] bufferPtr; if (rhs.size != 0) { bufferPtr = new char[rhs.size + 1]; strcpy(bufferPtr, rhs.bufferPtr); } else { bufferPtr = NULL; } } return *this; // enables chained assignment } Returning *this by reference makes chained assignment work, because the result of stringObject2 = stringObject3 is stringObject2 itself, which is then assigned to stringObject1, and so on.

  45. What is a constructor?

The designer of the object can have more than one constructor, a situation called overloading and then the compiler will select between them depending on exactly what arguments are passed to the constructor function.
