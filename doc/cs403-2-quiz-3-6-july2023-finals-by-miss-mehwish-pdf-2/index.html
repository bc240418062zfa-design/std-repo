MCQ 1:

____________are the structures defined for placing data in the attributes while designing the physical
design of a database.

Options:

a) Data types

b) Variables

c) Attributes

d) Objects

Correct Option: c) Attributes

MCQ 2:

If A → B and CB → D, then AC → D. The above rule follows _____________ inference rule.

Options:

a) Decomposition

b) Additivity

c) Augmentation

d) Pseudo transitivity

Correct Option: d) Pseudo transitivity

MCQ 3:

Which of the following is NOT related to partitioning and placement in a database?

Options:

a) Speed up the rate of useful work

b) Balance workload

c) Reduce workload

d) Speed up data transmission

Correct Option: d) Speed up data transmission

MCQ 4:

Atomicity is a feature of ______.

Options:

a) BCNF

b) 1NF

c) 2NF

d) 3NF

Correct Option: a) BCNF

MCQ 5:

Which of the following is a correct syntax of selecting all the columns from a table called PERSONS?

Options:

a) SELECT * FROM Persons

b) SELECT FROM * Persons

c) SELECT WHERE * Persons

d) SELECT * WHERE Persons

Correct Option: a) SELECT * FROM Persons

MCQ 6:

Denormalization is required to enhance _________.

Options:

a) Performance

b) Sharing of data

c) Data transmission

d) Data communication

Correct Option: a) Performance

MCQ 7:

Which of the following is NOT related to data manipulation language?

Options:

a) Insertion of information

b) Retrieval of information

c) Modification to the information

d) Control access to the information

Correct Option: d) Control access to the information

MCQ 8:

The database design prevents some data from being stored due to _______.

Options:

a) Redundancy

b) Insertion anomalies

c) Deletion anomalies

d) Update anomalies

Correct Option: b) Insertion anomalies

MCQ 9:

In ____________ the domains of attributes of a relation are atomic, that is they consist of single units
that cannot be broken down further.

Options:

a) Third normal form

b) First normal form

c) Second normal form

d) Augmentation

Correct Option: b) First normal form

MCQ 10:
________________ is the state of a database where a "course" cannot be inserted into the table
because this course has not been registered to any "student".

Options:

a) Updation anomaly

b) Redundancy

c) Deletion anomaly

d) Insertion anomaly

Correct Option: d) Insertion anomaly
