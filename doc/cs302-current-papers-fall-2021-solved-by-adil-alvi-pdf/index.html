2) Names of volatile memory?
Volatile memory is computer memory that requires power to maintain the stored information.
Most modern semiconductor volatile memory is either Static RAM or dynamic RAM.

3) Types of edge-triggered flip-flops?
Three different types of edge-triggered flip-flops are generally used in digital logic circuits.
S-R edge-triggered flip-flop
D edge-triggered flip-flop
J-k edge-triggered flip-flop
Each flip-flop has two variations, that is, it is either positive edge-triggered or negative edge
Triggered.

4) What is Mod-n Counters?
The term Mod represents the Modulus of the counter which is the total number of unique states
through which the counter will sequence through. A 3-bit Asynchronous counter can count up
from 0 to 7 or count down from 7 to 0. The 3-bit counter has 8 different states represented by the
8 outputs 0 to 7.

5) Difference between SRAM and DRAM?
The architectural difference between the two is that DRAM uses transistors and capacitors in an
array of repeating circuits (where each circuit is one bit), whereas SRAM uses several transistors
in a circuit to form one bit.

6) Applications of shift register?
Shift register is used as Parallel to serial converter, which converts the parallel data into serial
data.
Shift register is used as Serial to parallel converter, which converts the serial data into parallel
data.

11) CS, OE and W stand for?

12) How many flip-flop are required to make a mod-32 binary counter?
For a mod N counter, the number of flip-flops that are required is less than or equal to 2 to the
power 'n', where n is a positive integer, i.e. N ≤ 2ⁿ.
Therefore, for a mod 32 counter, it can be calculated as:-
32 = 2⁵, where n = 5
So, 5 flip-flops are required to make a mod-32 binary counter.

14) How can calculate the frequency of an unknown signal?
The frequency of a particular event is accomplished by counting the number of times that event
occurs within a specific time interval, then dividing the count by the length of the time interval.

15) Explain J-k flip flop of race condition?
Race Around Condition In JK Flip-flop – For J-K flip-flop, if J=K=1, and if clk=1 for a long
period of time, then Q output will toggle as long as CLK is high, which makes the output of the
flip-flop unstable or uncertain. This problem is called race around condition in J-K flip-flop.

19) Explain Sample and Hold Operation?
In electronics, a sample and hold (also known as sample and follow) circuit is an analog device
that samples (captures, takes) the voltage of a continuously varying analog signal and
holds (locks, freezes) its value at a constant level for a specified minimum period of time.

20) Difference between latches and flip flop?
Both latches and flip-flops are circuit elements whose output depends not only on the current
inputs, but also on previous inputs and outputs. The difference between a latch and a flip-flop
is that a latch does not have a clock signal, whereas a flip-flop always does.

22) What is d flip-flop latch gate operations?
The D flip-flop is an edge triggered device which transfers input data to Q on clock rising or
falling edge. Data Latches are level sensitive devices such as the data latch and the transparent
latch.
