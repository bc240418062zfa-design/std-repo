1. TABLE LOOKUP: In Table Lookup, binding or mapping is stored in a table in memory,
which the software searches when it needs to resolve an address.
2. CLOSED-FORM COMPUTATION: In Closed-form computation, the protocol address
assigned to a computer is chosen carefully so that computer’s hardware address can be computed
from the protocol address using basic Boolean and arithmetic operations.
3. MESSAGE EXCHANGE: In Message Exchange, Computers exchange messages across a
network to resolve an address. One computer sends a message that requests an address binding
(translation) and another computer sends a reply that contains the requested information.

smaller than outbound network MTU.
