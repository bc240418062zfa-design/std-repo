1. For a web page, if you write 10 spaces in your text, the browser will remove _____________ of them.
   Options:
   a) one
   b) 9
   c) none
   d) all
   Correct option: d) all

2. From the code given below, which one of the following elements is a selector?
   ```css
   H1 { color: blue; font-size: 12px; }
   ```
   Options:
   a) Color: blue
   b) Font-size: 12px
   c) H1
   d) None of the above
   Correct option: c) H1

3. Which of the following is a block element?
   Options:
   a) <li>
   b) <span>
   c) <img>
   d) <a>
   Correct option: a) <li>

4. The advantage(s) of CSS is/are:
   Options:
   a) Superior Styles to HTML
   b) Separation of document contents from document properties
   c) High Performance
   d) All of the above
   Correct option: d) All of the above

5. The default color for a page is defined in the _______ selector.
   Options:
   a) Heading Tag
   b) HTML Tag
   c) Body Tag
   d) Container Tag
   Correct option: c) Body Tag

6. Which of the following is the correct property to define the text size for an HTML element?
   Options:
   a) fontsize
   b) font-size
   c) fontsize
   Correct option: b) font-size

7. Which of the following list-style-type is supported by <ul> in HTML?
   Options:
   a) circle
   b) roman
   c) lower-alpha
   d) upper-alpha
   Correct option: a) circle

8. Which of the following tag is used to add a caption to an HTML table?
   Options:
   a) <cp>
   b) <caption>
   c) <c>
   d) <addcaption>
   Correct option: b) <caption>

9. In HTML, <blockquote> element is used ________.
   Options:
   a) For short quotation
   b) To block the quotation
   c) To block unauthorized access
   d) For long quotation
   Correct option: d) For long quotation
