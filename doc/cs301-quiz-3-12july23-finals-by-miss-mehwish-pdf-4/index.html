MCQ 1:

In double left-right rotation in the AVL tree, the single _______ rotation is carried out first, followed by a
single _______ rotation.

Options:

a) left, left

b) right, right

c) right, left

d) left, right

Correct Option: c) right, left

MCQ 2:

A Threaded Binary Tree is a binary tree in which every node that does not have a right child has a
THREAD (in actual sense, a link) to its _______ successor.

Options:

a) level order

b) preorder

c) inorder

d) postorder

Correct Option: c) inorder

MCQ 3:

An expression tree will always be a/an _______.

Options:

a) strictly binary tree

b) AVL tree

c) heap

d) binary search tree

Correct Option: a) strictly binary tree

MCQ 4:

In which case of insertion do we require a double rotation to make the AVL tree balanced?

Options:

a) An insertion into the left subtree of the right child of alpha.

b) An insertion into the right subtree of the right child of alpha.

c) An insertion into the left subtree of the left child of alpha.

d) To balance the AVL tree, double rotation is never required.

Correct Option: a) An insertion into the left subtree of the right child of alpha.

MCQ 5:

In Huffman encoding, codes are sent to the receiver in _______ format.

Options:

a) Hexadecimal

b) Binary

c) ASCII

d) Octal

Correct Option: b) Binary

MCQ 6:

A binary tree with 45 internal nodes has _______ links to external nodes.

Options:

a) 45

b) 90

c) 44

d) 46

Correct Option: d) 46

MCQ 7:

If an expression tree is correct, then its root should have _______.

Options:

a) an operator

b) an operand

Correct Option: a) an operator

MCQ 8:

The maximum height of the AVL tree is _______.

Options:

a) 4.44log2n

b) 1.44

c) 1.44log2n

d) log2n

Correct Option: c) 1.44log2n

MCQ 9:

The parse tree used by the compiler is equivalent to _______.

Options:

a) Complete binary tree

b) AVL tree

c) Binary search tree

d) Expression tree

Correct Option: d) Expression tree
