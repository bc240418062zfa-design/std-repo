THE LATIN SQUARE DESIGN

                 LECTURE NO.5

                    DESCRIPTION
        When the variation is found in two directions, it becomes necessary to
remove these two sources of variation simultaneously. This is done by
simultaneous blocking of experimental units in two mutually perpendicular
directions called rows and columns. Since each row and each column is a
complete block, the grouping for a balanced arrangement is performed by
imposing the restriction that each treatment must appear “ once and only once”
in each row and in each column.

         If there are “k” treatments then the experimental area will be divided
into “k” rows and “k” columns in k x k plots or experimental units. As the
experiment is laid out in a square pattern and the treatments are then assigned at
random to plots or experimental units. Such a double blocking of experimental
units and a corresponding double random assignment of treatments is called
“Latin Square Design”.

                                   LAYOUTs
         Latin squares are always constructed by rotations, e.g. in the case of 4
treatments A, B, C and D, we get

                      A            B            C            D

                      B            C            D            A

                      C            D            A            B

                      D            A            B            C

         A large number of distinct Latin squares can be derived by interchanging
rows and columns of a standard Latin square, where a standard Latin square is a
Latin square in which the treatments in the first row and first column are arranged
in alphabetical or numerical order.

         A standard Latin square is also called a reduced Latin square.

 There is only one standard square for a 2 x 2 Latin square as,

                                    A        B

                                    B        A

 And for 3 x 3 Latin square we have also one standard square such as,

                               A         B       C

                                B       C        A

                                C       A        B

 But for a 4 x 4 Latin square, there are four possible standard squares as,

      A       B       C       D                 A       B       C        D
      B       A       D       C                 B       A       D        C
      C       D       A       B                 C       D        B       A
      D       C       B       A                 D       C       A        B

      A       B       C       D                 A       B       C       D
      B       C       D       A                 B       D       A        C
      C       D       A       B                 C       A       D        B
      D       A       B       C                 D       C        B       A

         Each Latin square of k x k yields k! (k-1)! Different squares by permuting
the rows except first and all the k columns. According we may obtain from a
square of design.

                             2x2               2! (2-1)! = 2

                             3x3               3! (3-1)! = 12

                             4x4               4! (4-1)! = 576

                                               5! (5-1)! = 161280
