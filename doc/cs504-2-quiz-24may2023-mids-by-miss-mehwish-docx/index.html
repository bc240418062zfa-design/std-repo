1. Software development is a step-by-step process, and in ____________ phase of software development Business Objective of an organization gets cleared.
   Options:
   a) Development
   b) Maintenance
   c) Vision
   d) Definition

   Correct option: c) Vision

2. In ____________ phase of software development, Requirement Engineer focuses on realizing the Business Object of an underdeveloped product.
   Options:
   a) Development
   b) Definition
   c) Vision
   d) Maintenance

   Correct option: a) Development

3. Which of the given components of the software engineering framework provides different techniques that can be used to perform a particular task?
   Options:
   a) Tools
   b) Methods
   c) Quality Focus
   d) Processes

   Correct option: b) Methods

4. Many of the problems encountered in software development are attributed to shortcomings in __________.
   Options:
   a) Coding
   b) Testing
   c) Maintenance
   d) Requirement Gatherings

   Correct option: d) Requirement Gatherings

5. UML is a language for ________.
   Options:
   a) High-level Programming
   b) Creating diagrams only
   c) Modeling and Design
   d) Low-level Programming

   Correct option: c) Modeling and Design

6. In a Data Flow Diagram, the entity or system outside the boundary of the system is called a(n) ________.
   Options:
   a) Process
   b) Data Store
   c) External Agent
   d) Data Flow

   Correct option: c) External Agent

7. In the case of _________ approach, data is decomposed according to functionality requirements.
   Options:
   a) Action-oriented
   b) Process-oriented
   c) Object-oriented
   d) Event-oriented

   Correct option: c) Object-oriented

8. The most important and critical stage in object-oriented design is the appropriate classification of _________.
   Options:
   a) Methods
   b) Functions
   c) Relationships
   d) Objects

   Correct option: d) Objects

9. An external entity that interacts with a system is called a(n) ________.
   Options:
   a) Use case
   b) Stakeholder
   c) Association
   d) Actor

   Correct option: d) Actor

10. Which one of the following is the external quality of a software product?
    Options:
    a) Low Coupling
    b) Correctness
    c) Cohesion
    d) Concision

    Correct option: b) Correctness
