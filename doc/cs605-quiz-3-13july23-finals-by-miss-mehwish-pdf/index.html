1. Instead of going through the entire design in a meeting, we narrow down the focus by conducting
_________ for each component, or small group of components.

Options:

- Testing

- Walkthroughs

- Informal Reviews

Correct Option: Walkthroughs

2. The first task in concept development project is to:

Options:

- Determine the scope of the concept

- Determine the resources required for the concept

- Determine the test cases for the concept

- Determine the cost of the concept

Correct Option: Determine the scope of the concept

3. ___________ involves rework, repair, and failure mode analysis of the product.

Options:

- Appraisal Cost

- External Failure Cost

- Internal Failure Cost

- Prevention Cost

Correct Option: Internal Failure Cost

4. __________ is one of the techniques to prepare project schedule once we have defined "task
network".

Options:

- System resource negotiation method (SRNM)

- Program evaluation and review techniques (PERT)

- Strategic Schedule Development technique (SSDT)

- Critical Communication path method (CCPM)

Correct Option: Program evaluation and review techniques (PERT)

5. Following are effective guidelines for Review EXCEPT

Options:

- Be sensitive to personal egos

- We need to review the product not the producer

- Errors should be pointed out gently

- Be sensitive to personal preferences

Correct Option: Be sensitive to personal preferences

6. FTR is a quality control activity performed by software engineers, it stands for:

Options:

- Formatted Technical Review

- Formal Technical Review

- Fetched Technical Requirement

- Feasibility of Technical Requirement

Correct Option: Formal Technical Review

7. Formula for the total number of Channels of communication involving N people is given by:

Options:

- C = N(N-1)

- C = N(N-1)/2

- C = N(N+1)*2

- C = N(N+1)

Correct Option: C = N(N-1)/2

8. It is noted that a/an __________ review can be worse than no review at all.

Options:

- Normal

- Controlled

- NormalControlled

Correct Option: Normal

9. In order to use the PERT and CPM, which one of the followings is NOT required?

Options:

- Estimation of effort

- Decomposition of tasks – also known as the work breakdown structure (WBS)

- Teams communication mode details

- Interdependencies

Correct Option: Teams communication mode details

10. Error-free designed software requirements but wrongly gathered by requirement engineers will
return _________.

Options:

- Unwelcome product

- Desired product

- Absolutely correct product

- Accurate product

Correct Option: Unwelcome product
