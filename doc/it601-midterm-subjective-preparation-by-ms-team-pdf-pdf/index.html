Different components of a system have objectives?

The components of an IT system and their objectives include:

     Computing Machines → Provide processing power (Servers,
     Workstations).
     Software → Enable functionality (Operating Systems, Applications).
     Network → Facilitates communication (Routers, Switches).
     Services → Offer functionalities (Web, DNS, DHCP).
     Users → Interact with the system.
     Processes → Maintain operations (System updates, backups).

5 levels mai sy koi b level ho skta ha?

This refers to SAMM (System Administration Maturity Model) levels:

   1. Initial (Ad-hoc processes) → No formal process.
   2. Repeatable (Disciplined process) → Basic documentation.
   3. Defined (Standard, Consistent process) → Well-documented procedures.
   4. Managed (Predictable process) → Measured and controlled processes.
   5. Optimizing (Continuously improving) → Ongoing refinement and
       automation.

MTTF and MTTR Stand For?

    MTTF (Mean Time to Failure) → Average time before a system fails.
   MTTR (Mean Time to Recovery) → Average time to fix and restore a
     failed system.

Question tha k Windows ki operations bataen?

Windows Operating System performs various operations, including:

     File Management → Organizes files and folders.
     Process Management → Manages running applications and background
     processes.
     Memory Management → Allocates RAM to active programs.
     User Management → Creates and manages user accounts.
     Networking → Provides network connectivity through TCP/IP.
     Security Management → Includes firewalls, encryption, and user

CPU ki performance kaisi hai?

CPU performance depends on:

     Clock Speed (GHz) → Higher GHz means faster processing.
     Number of Cores → Multi-core CPUs handle tasks efficiently.
     Cache Size → L1, L2, L3 cache improves processing speed.
     Instruction Set → Advanced architectures (e.g., x86, ARM) optimize
      performance.

States wala bhi question tha ik?

This refers to Evard’s Computer Machine Life Cycle which includes:

   1. New → Freshly unpacked system.
   2. Clean → OS installed, but not configured.
   3. Configured → Ready for use, properly set up.
   4. Unknown → Misconfigured, outdated, or compromised state.
   5. Off → Shut down or removed from the system.

Buy in bulk allocate fraction waly ki advantages thi?

Advantages of buying in bulk and allocating fractions:

     Cost Efficiency → Discounts on large purchases.
     Resource Optimization → Allocate only what is needed, reducing waste.
     Scalability → Easily expand IT resources as needed.
     Better Planning → Reduces frequent purchases and administrative
     overhead.

Server ki RAMs ke baray mein batana tha?

Server RAMs are different from desktop RAMs in terms of capacity, reliability,
and performance.

     Types of Server RAM:
        o ECC RAM (Error-Correcting Code RAM): Used in servers for
           error detection and correction.
        o Buffered/Registered RAM: Used in high-performance servers to
           reduce electrical load on memory controllers.
     Speed and Cost:
        o Server RAMs have higher speeds, typically 2400MHz to 6400MHz.
        o More expensive than desktop RAM due to error correction and
           higher reliability.
