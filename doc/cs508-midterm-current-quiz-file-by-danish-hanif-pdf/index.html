Question #1: Which of the following languages was designed as a hardware description
language?

A) PASCAL

B) APL

C) PL/1

D) SIMULA

Select the correct option:

Correct Answer: D) SIMULA

Question #2: In ________, there is no need to declare a variable, and it takes the form of
an assigned value.

A) CAL

B) GOL

C) SNOBOL

D) Ada

Select the correct option:

Correct Answer: C) SNOBOL

Question #3: The $ operator in SNOBOL is used as both a/an _______ and _______
operator.

A) Internal, binary

B) Unary, binary

C) Unary, external

D) External, internal

Select the correct option:

Correct Answer: B) Unary, binary

Question #4: Space operator in SNOBOL can be used for _____________.

A) End Statement

B) Concatenation

C) Replacement

D) Immediate Assignment

Select the correct option:

Correct Answer: B) Concatenation

Question #5: COBOL was the first language that brought the concept of __________.

A) Structure

B) Records

C) Object

D) Variable

Select the correct option:

Correct Answer: A) Structure

Question #6: SIZE function in SNOBOL language is used to return the size of _________.

A) String

B) Variable

C) Operator

D) Keyword

Select the correct option:

Correct Answer: A) String

Question #7: If z = '10' and x = 5 * -z + '10.6' in SNOBOL4, what would be the resultant
value of x?

A) 30.0

B) 39.4

C) -30.0

D) -39.4

Select the correct option:

Correct Answer: D) -39.4

Question #8: 15-30 function points show that the language level is:

A) 1-3

B) 4-8

C) Above 55

D) 16-23

Select the correct option:

Correct Answer: B) 4-8

Question #9: You can return structures but not _____ from a function in the C
programming language.

A) Pointers

B) Numbers

C) References

D) Arrays

Select the correct option:

Correct Answer: D) Arrays

Question #10: The first electronic computer was _________.

A) ENIAC

B) IBM x86

C) Baggage Analytical Engine

D) Intel 386

Select the correct option:

Correct Answer: A) ENIAC

Question #1: In SNOBOL4, elements of the array _______.

a) must be of Integer type

b) not necessarily of the same type

c) must be of the same type

d) must be of different types

Answer: b) not necessarily of the same type

Question #2: Which of the following post-test loop is not supported in Ada language?

a) Infinite loop

b) ‘for’ loop

c) ‘do while’ loop

d) ‘while’ loop

Answer: c) ‘do while’ loop

Question #3: The alternative of ‘structure’ data type in Ada language is:

a) Class

b) Array

c) Union

d) Record

Answer: d) Record

Question #4: What will be the result of the following function call in LISP?

(/ 7.0 2)

a) 3.5

b) 9.0

c) 7.0

d) 3.0

Answer: a) 3.5

Question #5: In ADA programming language, ** operator is used for ___________.

a) Remainder

b) Range

c) Membership

d) Exponentiation

Answer: d) Exponentiation

Question #7: In SNOBOL4, the ____________ function is used to replace one character with
another in the entire string.

a) CHANGE

b) ALTERATION

c) EXCHANGE

d) REPLACE

Answer: a) CHANGE
Question #8: Which of the following features of Ada language is similar to the pointers
in C++?

a) Access Types

b) Records

c) Arrays

d) Structures

Answer: a) Access Types

Question #9: Which of the following is the membership operator in Ada?

a) ^

b) mem

c) in

d) @

Answer: c) in

Question #10: Generics in Ada language allow parameterization of _____________.

a) Variables

b) Subprograms

c) Programs

d) Objects

Answer: b) Subprograms
