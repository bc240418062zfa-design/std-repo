   1. A Tree is a collection whose entries have a hierarchical organization similar to that of an
      organization chart.
   2. What does a primitive data type in a programming language allow for? (Declaration,
      allocation, and manipulation of data)
   3. The protocol that ensures older transactions are given priority when accessing locked items
      is called the ______ protocol. (Wound-Wait)
   4. Persistent objects in a database are distinct from transient objects because ______.
      (saved after program termination)
   5. What is the primary focus of the implementation phase in software engineering? (Writing
      programs and creating data files)
   6. If information hiding is not properly implemented, what is its main effect on a software
      program? (Errors occur during module development)
   7. Why do many software engineers argue for incorporating testing into various stages of
      software development? (To eliminate the need for testing)
   8. During the implementation phase of software engineering, what task is typically
      performed? (Writing Programs)
   9. A car-making factory makes cars for its clients. In the Factory Design Pattern, the factory
      is considered as a ______. (Class)
   10.GOMS model is based on ______. (Human Behaviors)
   11.An array is a ______ block of data whose entries are of the same type. (Rectangular)
   12.ISO makes software ______ for software companies to guarantee quality Control.
      (standards)
   13.To control access to information within a database, database systems rely on ______.
      (Schemas, Subschemas)
   14.What does the term "Waterfall" in the Waterfall Model analogy represent? (The strict,
      one-directional flow of the development process)
   15.How are fields in an aggregate type usually accessed? (Field Names)
   16.What is another name for a Program Counter in the context of CPUs? (Instruction
      Pointer)
   17.A ______ is a storage area that contains an encoded address. (Pointer)
   18.What is the benefit of the Decorator Pattern during software development? (It offers a
      standardized way of implementing a system)
   19.Operations that are only partially completed in commercial systems might lead to ______
      information in the database. (Incomplete Information)
   20.What does Basis Path Testing aim to achieve? (To ensure every instruction is executed
      at least once)
   21.In a tree structure, what is the top node called? (Root Node)
   22.Which register holds the address of the next instruction to be executed? (Program
      Counter)
