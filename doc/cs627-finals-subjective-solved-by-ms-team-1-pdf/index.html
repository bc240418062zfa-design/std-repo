2026     16. What are White, Black, and Grey Risks in OS Security?
               o   White Risk: Known and documented security vulnerabilities that
                   can be mitigated using standard security measures (e.g., outdated
                   software with available patches).
               o   Black Risk: Unknown and unpredictable vulnerabilities that can
                   be exploited without prior knowledge (e.g., zero-day exploits).
               o   Grey Risk: Semi-known vulnerabilities where some aspects are
                   understood but not fully mitigated (e.g., partial security patches,
                   misconfigurations).
