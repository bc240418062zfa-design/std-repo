1)how many categories to improve data quality
Ans:
Data Accuracy:
Ensuring that data is correct and free from errors, inaccuracies, and inconsistencies.
Data Completeness:
Verifying that all necessary data is present, and there are no missing values or incomplete records.
Data Consistency:
Ensuring data consistency across different sources, systems, and time periods by standardizing formats and units
of measurement.
Data Timeliness:
Ensuring that data is up-to-date and relevant for its intended use, with processes in place for regular data updates.
Data Relevance:
Assessing whether the data collected is relevant to the business objectives and decision-making processes.
Data Validity:
Checking that data conforms to defined rules, constraints, and business logic.
Data Integrity:
Ensuring data integrity through measures like enforcing referential integrity in databases and preventing data
corruption.
Data Uniqueness:
Eliminating duplicate records or entries in the data, which can distort analysis and lead to inaccuracies.
Data Consolidation:
Bringing together data from various sources into a unified, consistent format through data integration processes.

Data Profiling:
