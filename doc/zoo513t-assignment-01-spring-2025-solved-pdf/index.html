Explain the major classes included within the Subphylum Craniata and
Provide examples of each.

The Subphylum Craniata (sometimes used interchangeably with Vertebrata) comprises those
chordates that possess a true skull (cranium) enclosing the brain. Below is an overview of its
major (extant) classes, arranged phylogenetically from the most “primitive” jawless groups up
through the jawed vertebrates.

1. Class Myxini (Hagfishes)

   •   Key features:
          o Jawless, eel-like body
          o Movable knotting behavior for feeding
          o Produces large quantities of slime as a defense
   •   Example:
          o Eptatretus stoutii (Pacific hagfish)

2. Class Petromyzontida (Lampreys)

   •   Key features:
          o Also jawless but with a toothed, suction-cup mouth
          o Lifecycle often includes a filter-feeding larval (ammocoete) stage
          o Many are parasitic as adults
   •   Example:
          o Petromyzon marinus (sea lamprey)

Gnathostomata (Jawed Vertebrates)

With the evolution of jaws, vertebrates diversify into bony and cartilaginous groups.

3. Class Chondrichthyes (Cartilaginous Fishes)

   •   Key features:
          o Skeleton made of cartilage rather than bone
          o Placoid scales (“dermal denticles”)
          o Includes both constantly-moving filter feeders and active predators
   •   Examples:

          o   Ray: Manta birostris (giant manta ray)

4. Class Actinopterygii (Ray‐finned Fishes)

   •   Key features:
          o Fins supported by long, bony rays
          o Represents by far the largest vertebrate radiation (>30,000 species)
          o Swim bladder often present for buoyancy
   •   Examples:
          o Salmo salar (Atlantic salmon)
          o Perca fluviatilis (European perch)

5. Class Sarcopterygii (Lobe‐finned Fishes)

   •   Key features:
          o Fleshy, lobed fins with a bony central axis
          o Gave rise to all tetrapods
   •   Examples:
          o Latimeria chalumnae (West Indian coelacanth)
          o Lungfishes (Neoceratodus forsteri, Australian lungfish)

6. Class Amphibia (Amphibians)

   •   Key features:
          o Dual life stages (aquatic larva with gills → terrestrial or semi-aquatic adult with
              lungs)
          o Moist, glandular skin often used in gas exchange
   •   Examples:
          o Rana temporaria (common frog)
          o Ambystoma mexicanum (axolotl)

7. Class Reptilia (Reptiles)

   •   Key features:
          o Amniotic egg (with watertight membranes)
          o Scaly, keratinized skin to reduce water loss
          o Ectothermic (“cold-blooded”) metabolism

8. Class Aves (Birds)

   •   Key features:
          o Feathers derived from reptilian scales
          o High metabolic rate and endothermy (“warm-blooded”)
          o Forelimbs modified into wings (in most)
   •   Examples:
          o Passer domesticus (house sparrow)
          o Aptenodytes forsteri (emperor penguin)

9. Class Mammalia (Mammals)

   •   Key features:
          o Hair or fur covering
          o Mammary glands producing milk for young
          o Three middle-ear bones and a single dentary bone in the lower jaw
   •   Examples:
          o Homo sapiens (human)
          o Canis lupus familiaris (domestic dog)

Each of these classes represents a major evolutionary step within Craniata—whether the origin
of a skull, jaws, bony skeleton, limbs, or endothermy—and together they encompass the vast
diversity of vertebrate life we see today.
