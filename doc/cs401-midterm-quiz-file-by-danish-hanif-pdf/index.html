STI stands for?

a) Set Instruction
b) Set Interrupt
c) Standard Timer Interrupt
d) Set the Interrupt flag

Answer: b) Set Interrupt

As a result of base+offset addressing, the address that is generated is called a (an)
_____________ address.

a) Net address
b) Effective address
c) Elective address
d) Additive address

Answer: b) Effective address

Question 3: Which of the following keywords is used to define two bytes in memory?

a) DB
b) DN
c) DD
d) DW

Answer: c) DD

Question 4: SP is associated (by default) with __________ register.

a) ES
b) SS
c) CS
d) DS

Answer: b) SS

Question 5: Which of the following instruction is equivalent to multiplying the value of
AX by 8?

a) SHL AX, 8
b) MUL AX, 3
c) SAL AX, 8
d) SHL AX, 3

Answer: a) SHL AX, 8

Question 6: ___________ cannot appear as an operand in any instruction. It is used for
accessing instructions.

a) AH
b) BH
c) SS
d) IP

Answer: d) IP

Question 7: In case of a 32-bit processor, the size of an accumulator register will be
___________ bits.

a) 32
b) 16
c) 8
d) 64

Answer: a) 32

Question 8: In Shift logical Left (SHL), the ______________ bit is dropped into the carry
flag.

a) Most significant
b) Second least significant
c) Third least significant
d) Least significant

Answer: a) Most significant

Question 9: Registers are storage cells ________________________.

a) Inside the processor
b) Both inside and outside the processor
c) Outside the processor
d) Inside the memory

Answer: a) Inside the processor

Question 10: In ____________________, every bit moves one position to the right, and the
bit dropped from the right is inserted at the left. The dropped bit is also copied into the
carry flag.

a) Rotate through Carry Right (RCR)
b) Rotate through Carry Left (RCL)
c) Rotate Left (ROL)
d) Rotate Right (ROR)

Answer: d) Rotate Right (ROR)

Question #1: Which of the following is the number of operands for ADC (Add with
Carry) instruction?

A) 3
B) 2

C) 1
D) 4

Correct Answer: B) 2

Question #2: XOR can also be used as a _______________ to invert selective bits.

A) masking operator
B) multiplication operator
C) source operand
D) destination operand

Correct Answer: A) masking operator

Question #3: Execution of CALL instruction affects ________ number of bits in the Flags
register.

A) 0
B) 3
C) 5
D) 1

Correct Answer: B) 3

Question #4: Stack is a data structure that behaves in a First In Last _______ manner.

A) Out
B) Add
C) In
D) Push

Correct Answer: C) In

Question #5: We can convert a digit into its ASCII representation by adding ____________
to it.

A) 0x30
B) 0x05
C) 0x20
D) 0x10

Correct Answer: A) 0x30

Question #6: An important role of the stack is in the creation of _______ variables that are
only needed while the subroutine is in execution and not afterwards.

A) Global
B) Public
C) Private
D) Local

Correct Answer: D) Local

Question #7: __________ can be used to check whether particular bits of a number are set
or not.

A) OR
B) AND
C) NOT
D) XOR

Correct Answer: B) AND

Question #8: Which of the following instructions is used for non-destructive AND
operation?

A) CMP
B) TEST

C) ADC
D) NAND

Correct Answer: B) TEST

Question #9: In assembly language, integer division results in __________ quotient and
_________ remainder.

A) floating point, floating point
B) floating point, integer
C) integer, floating point
D) integer, integer

Correct Answer: D) integer, integer

Question #10: Call instruction changes the values of __________ and __________ registers.

A) IP, SP
B) IP, DX
C) IP, AX
D) IP, AL

Correct Answer: A) IP, SP
