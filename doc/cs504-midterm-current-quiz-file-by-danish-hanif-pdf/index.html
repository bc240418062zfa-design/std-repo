In a UML-based Object-Oriented model of a system, a composition relation between
two objects is shown by a ________________ sign on the Whole side of a relation line.

A. half arrowhead

B. dot

C. unfilled diamond

D. filled diamond

Answer:

The correct answer is: C. unfilled diamond

Question #2:

The most important and critical stage in object-oriented design is the appropriate
classification of _________.

A. relationships

B. methods

C. functions

D. objects

Answer:

The correct answer is: D. objects

Question #3:

Software Engineering is the combination of tools, techniques, and ________________.

A. Processes

B. Maintenance

C. Testing

D. Design

Answer:
The correct answer is: D. Design

Question #4:

The architecture components for product engineering are:

A. data, hardware, software, procedures

B. documentation, hardware, people, procedures

C. data, documentation, hardware, software

D. data, hardware, software, people

Answer:

The correct answer is: C. data, documentation, hardware, software

Question #5:

Coupling is a measure of _______ of a module or component.

A. Composition

B. Dependence

C. Independence

D. Aggregation

Answer:

The correct answer is: C. Independence

Question #6:

By leveling a DFD (adding more levels of abstraction), we mean:

A. Make its structure uniform

B. Splitting it into different levels

C. Expanding a process into one with more sub-processes giving more detail

D. Summarizing a DFD to specify only the essentials

Answer:

The correct answer is: B. Splitting it into different levels

Question #7:

A _______ is not the real product but just a real-looking mock-up of what would be
eventually delivered.

A. Software

B. Program

C. Prototype

D. Test Case

Answer:

The correct answer is: C. Prototype

Question #8:

A tangible entity in real life is called _____.

A. Class

B. Sub-Class

C. Object

D. Functions

Answer:

The correct answer is: C. Object

Question #9:

A context diagram is used:

A. as an aid to programmers

B. as an aid to system design

C. in systems analysis of very complex systems

D. as the first step in developing a detailed DFD of a system

Answer:

The correct answer is: B. as an aid to system design

Question #10:

In __________ relationship, a class shares the structure and behavior defined in another
class.

A. Inheritance

B. Uses

C. Aggregation

D. Composition

Answer:

The correct answer is: A. Inheritance

Question 1: Which relationship is concerned with classes, not with the class
instantiates?

A. Association
B. Composition
C. Aggregation
D. Inheritance

Correct Answer: D. Inheritance

Question 2: Which component of the software engineering framework provides
automated or semi-automated support in software development?

A. Quality Focus
B. Processes
C. Tools
D. Methods

Correct Answer: C. Tools

Question 3: In a Data Flow Diagram, the entity or system outside the boundary of this
system is called:

A. Data Flow
B. Process
C. Data Store
D. External Agent

Correct Answer: D. External Agent

Question 4: When two components of a system are using the same global data area,
they are related as:

A. External Coupling
B. Data Coupling
C. Content Coupling
D. Common Coupling

Correct Answer: D. Common Coupling

Question 5: In the case of the action-oriented approach, data is decomposed according
to:

A. Functionality requirements
B. Object requirements
C. Corresponding domain model
D. Compatibility with object interface

Correct Answer: A. Functionality requirements

Question 6: Which of the following is not supported by a maintainable design?

A. Adding new features
B. Higher maintenance cost
C. Change
D. Debugging

Correct Answer: B. Higher maintenance cost

Question 7: In UML Object Model Notation, __________.

A. Relationships among classes and sub-classes are expressed
B. Mathematical problems are visualized
C. Graphs and tables are used to explain Software Engineering principles
D. C++ language-specific programs are constructed

Correct Answer: A. Relationships among classes and sub-classes are expressed
Anonymous

these requirements consume.

A. Up Parsing
B. Data Flow Analysis
C. Source and Sink Analysis
D. Down Parsing

Correct Answer: C. Source and Sink Analysis
