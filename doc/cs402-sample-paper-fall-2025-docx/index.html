Question No: 1      (Marks: 01) - Please choose the correct option

What is “y” in pumping lemma version 1?
    A. It is a non-null string                                                     (from lec no. 26 and page no.73)
    B. It is a null-able string
    C. It is a non-null string with initial state
    D. It is a null-able string with initial state

Reason:
In Pumping Lemma (Version 1 for Regular Languages), the string is divided as:
w = xyz
with these conditions:
    • ∣y∣> 0 → y must be non-empty (non-null)
    • ∣xy∣≤ p
    • xyiz∈L for all i ≥ 0
There is no condition about the initial state in the definition of y.
