Software testing is an important part of software development as it is helpful for detecting errors
and bugs in a software system. Software testing helps validate the software system whether it
works as expected or not. Test cases are implemented to check that the system which is to be tested
is working as specified in the requirement documents or not. It is estimated that software testing
consumes almost 50% of the total software development efforts. Software testing shows presence
of errors and bugs in a software system but it cannot prove absence of errors. Software testing has
always been an important technique to validate the system under test.

Software systems are increasingly getting complex these days. Some of the reasons are:

      Size of the software increases due to growing requirements
      Time to market decreases (less time is available for software development due to market
       competition)
      Increasing emphasis on GUI component

There are several reasons that contribute these defects, e.g.

      Poor Requirements Elicitation: Erroneous, incomplete, and/or inconsistent software
       requirements.
      Inadequate Design: Fundamental design flaws in the developed software.

      Improper Implementation: Mistakes by the development team in software
       implementation, chip fabrication, wiring, programming faults, and malicious code.

      Defective Support Systems: Poor programming languages, faulty compilers and
       debuggers, misleading development tools.
      Inadequate Testing of Software: Incomplete testing, poor verification, mistakes in
       debugging.
      Evolution: Sloppy software re-development or maintenance, introduction of new flaws in
       an attempt to fix old flaws, incremental escalation to inordinate complexity.

Defective software in certain domains can result in disastrous situations. Examples include:

      Faulty Communications: Loss or corruption of communication media, non-delivery of
       data, etc.
      Space Applications: Risk of loss of lives, spaceship launch delays, etc.
      Defense Systems: Mis-identification of friend or foe.
      Transportation: Risk of deaths, delays, sudden acceleration, inability to apply brakes, etc.
      Safety-critical Applications: Risk of deaths, and injuries.
      Health Care Applications: Risk of deaths, injuries, power outages, long-term health
       hazards (radiation).
      Money Management: Fraud, violation of privacy, shutdown of stock exchanges and
       banks, negative interest rates, etc.
      Control of Elections: Wrong results (intentional or non-intentional).

         Control of Jails: Technology-aided escape attempts and successes, accidental release of
          inmates, failures in software controlled locks.
         Law Enforcement: False arrests and imprisonments.
