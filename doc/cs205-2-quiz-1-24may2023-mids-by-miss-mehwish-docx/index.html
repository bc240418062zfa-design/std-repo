1. Question: A ________________ is a blueprint or roadmap for achieving Information Security objectives.
   Options:
   a) Standard
   b) Process
   c) Technology
   Correct option: a) Standard

2. Question: Layer 2 of the security transformation model emphasizes _____________.
   Options:
   a) Vulnerability management program
   b) PCI
   c) Security governance
   d) Identifying vulnerabilities through a risk-based approach
   Correct option: d) Identifying vulnerabilities through a risk-based approach

3. Question: Identifying vulnerabilities through a risk-based approach SOP is developed detailing the actions to be taken. Which of the following options is relevant?
   Options:
   a) People are trained on how to use the technology
   b) Competent experts are hired to run the process
   c) Security guidelines are documented
   d) SOP is developed detailing the actions to be taken
   Correct option: d) SOP is developed detailing the actions to be taken

4. Question: How is information security implemented?
   Options:
   a) By management
   b) By the business
   c) With the help of an information security program
   d) By IT security teams
   Correct option: c) With the help of an information security program

5. Question: The key factor related to cloud, mobile, IoT, and social is that ____________.
   Options:
   a) They are mainly being used in developing nations
   b) It has further complicated the already difficult task of achieving a strong security posture
   c) These new frontiers are not understood well
   d) Adoption is low
   Correct option: b) It has further complicated the already difficult task of achieving a strong security posture

6. Question: Which of the following programs is relevant when we are simply trying to "focus attention on security"?
   Options:
   a) A degree program
   b) Security education
   c) Security training
   d) Security awareness
   Correct option: b) Security education

7. Question: Which of the following statements is false?
   Options:
   a) COBIT has five enablers and seven principles
   b) PCI-DSS has six broad goals and twelve requirements
   c) PCI-DSS is applicable only to the credit card-related industry
   d) ISO 27001:2013 has ten short clauses and a long annex with 14 sections and 113 controls
   Correct option: a) COBIT has five enablers and seven principles

8. Question: People, process, and _____________ are together referred to as the Information Security Triad.
   Options:
   a) Procedure
   b) Policy
   c) Standard
   d) Technology
   Correct option: d) Technology

9. Question: Which variants of Microsoft SQL Server exist on the CIS website?
   Options:
   a) 2008, 2012, 2016
   b) 2012, 2014, 2016
   c) 2003, 2008, 2012
   d) 2008, 2012, 2014
   Correct option: d) 2008, 2012, 2014

10. Question: For effective information security implementation, the security journey should start with _____________.
    Options:
    a) Security hardening and vulnerability management of IT assets
    b) Penetration test
    c) Management commitment
    d) Developing comprehensive policies and procedures
    Correct option: c)
