Question No: 23 ( Marks: 3 )
What is periodic signal?

Solution:    p_60
A signal is called Periodic if it completes a pattern within a measurable
time frame called a Period and then repeats that pattern over identical
subsequent Periods
The completion of one full pattern is called a CYCLE
Period: Time required (in Seconds) to complete one full cycle, represented
by ‘T’.
