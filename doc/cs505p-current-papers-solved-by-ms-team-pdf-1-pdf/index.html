Network virtualization creates virtual network components (switches, routers,
firewalls) using software, making networks more flexible, scalable, and secure. It
allows multiple virtual networks to run on a single physical network without
interference.
Key Benefits:

     Easier network management
      Faster provisioning of new networks
      Better security and isolation
      Cost savings on physical infrastructure

1. What is a Virtual Machine?

A Virtual Machine (VM) is a software-based simulation of a physical computer
that runs an operating system (OS) and applications independently. It uses
virtualized resources like vCPU, vRAM, and vDisk instead of physical hardware.

2. What is a Virtual Switch in Hyper-V?

A Virtual Switch in Hyper-V is a software-based network switch that allows
Virtual Machines (VMs) to communicate with each other and the physical
network.
Types of Virtual Switches in Hyper-V:

     External vSwitch – Connects VMs to the physical network
     Internal vSwitch – Connects VMs with each other and the host machine

6. Main Purpose of Data Centers

A Data Center is a facility that houses servers and IT infrastructure to store,
process, and distribute data.

Key Purposes:

      Data Storage & Management – Store large volumes of data securely
      Hosting Websites & Applications – Provide cloud services
      Disaster Recovery – Backup critical business data
      Business Continuity – Ensure 24/7 access to data and services
      Cybersecurity – Protect sensitive data with advanced security

1. NoSQL

NoSQL (Not Only SQL) is a type of database designed to handle large-scale,
unstructured, or semi-structured data. Unlike traditional relational databases
(SQL), NoSQL databases do not rely on fixed schemas or tables.

Types of NoSQL Databases:

      Key-Value Stores (e.g., Redis, DynamoDB)
      Document Stores (e.g., MongoDB, CouchDB)
      Column-Family Stores (e.g., Cassandra, HBase)
      Graph Databases (e.g., Neo4j, ArangoDB)
