Question #1: What is the purpose of different API function variants in Windows?

A. To support various character encodings

B. To differentiate between uppercase and lowercase characters

C. To handle different programming languages

D. To provide compatibility with legacy systems

Answer: C. To handle different programming languages

Question #2: _______ convenient function converts file time into system time.

A. CompareFileTime

B. SystemTimeToFileTime

C. FileTimeToLocalFileTime

D. FileTimeToSystemTime

Answer: D. FileTimeToSystemTime

Question #3: CatFile() function takes ___________ parameters.

A. 3

B. 2

C. 4

D. 5

Answer: A. 3

Question #4: The termination handler cannot execute the _______________ statement.

A. Break

B. Return

C. Report

D. Continue

Answer: B. Return

Question #5: What is the return type of GetStdHandle() API?

A. LPDWORD

B. BOOL

C. HANDLE

D. DWORD

Answer: C. HANDLE

Question #6: Choose the correct option for a source code that uses only Windows APIs instead
of C Library functions.

A. Source code is portable

B. Source code cannot be compiled

C. Source code can only access some features of Windows

D. Source code will not remain portable

Answer: D. Source code will not remain portable

Question #7: ______ is the return type of SetFilePointer() function.

A. HANDLE

B. DWORD

C. BOOL

D. VOID

Answer: B. DWORD

Question #8: In NTFS based system, ___________ is the maximum allowed size for a single
file.

A. 2 TB

B. 32 TB

C. 16 TB

D. 28 TB

Answer: C. 16 TB

Question #9: In the RECORD structure, the data type of numNonEmptyRecords is
_______________.

A. Double

B. INT

C. BOOL

D. DWORD

Answer: B. INT

Question #10: Every subsequent read/write operation is performed at the _____ file
pointer position.

A. Current

B. Start

C. Middle

D. End

Answer: A. Current

The HeapAlloc() API has ___________ parameter(s).

Options:

a) 1

b) 3

c) 2

d) 4

Answer: c) 2

Question #2: Which of the following functions is used to generate a sound beep for 0.7
seconds with the frequency of 750?

Options:

a) Beep(700, 750)

b) Beep(750, 0.7)

c) Beep(750, 800)

d) Beep(750, 700)

Answer: b) Beep(750, 0.7)

Question #3: A file mapping handle returns _________ on failure.

Options:

a) TRUE

b) FALSE

c) NULL

d) UNDEFINED

Answer: c) NULL

Question #4: In comparison of DLL, executable library files are linked at _________ time.

Options:

a) Load

b) Link

c) Run

d) Compile

Answer: d) Compile

Question #5: If threads have separate memory spaces, then it will reduce
________________.

Options:

a) Direct memory access

b) Memory density

c) Access speed

d) Memory contention

Answer: d) Memory contention

Question #6: There are _____________ parameters taken by the HeapSize() API.

Options:

a) 2

b) 1

c) 4

d) 3

Answer: a) 2

Question #7: Which of the following is recommended to use while dealing with
memory-mapped file to look for EXCEPTION_IN_PAGE_ERROR exceptions?

Options:

a) SHE exception handling

b) HES exception handling

c) ESH exception handling

d) HE exception handling

Answer: a) SHE exception handling

Question #8: In the vectored exception handler, the value of FirstHandler parameter
specifies the __________ in which the handler will execute.

Options:

a) Order

b) Accuracy

c) Allocation of stack

d) Speed

Answer: a) Order

Question #9: In order to deallocate a block of heap, ____________ is used.

Options:

a) HeapFree()

b) HeapTruncate()

c) HeapDestroy()

d) HeapDelete()

Answer: a) HeapFree()

Question #10: Try and Catch keywords ___________ required for vectored exception
handlers.

Options:

a) must be

b) are

c) are not

d) are occasionally

Answer: c) are not
