3. Scenario: Running 3 Different Operating Systems

If you need to run 3 different operating systems (e.g., Windows, Linux, macOS)
on a single machine, you will need 3 Virtual Machines (VMs). Each VM will
have its own OS, running independently on a hypervisor (Type 1 or Type 2).

1. What is VirtualBox?

VirtualBox is a Type 2 Hypervisor developed by Oracle that allows users to run
multiple Virtual Machines (VMs) on a host operating system. It supports various
guest operating systems such as Windows, Linux, macOS, and Solaris.

Key Features:

      Open-source and free to use

By Maha Rana

     Supports hardware & software virtualization
     Runs on Windows, Linux, and macOS
     Provides snapshot & cloning options

2. Four Demerits of Virtual Machines (VMs)

  1. High Resource Usage – VMs consume a lot of CPU, RAM, and disk
      space, reducing performance.
  2. Slower Performance – Running multiple VMs on one host can cause
      performance bottlenecks.
  3. Single Point of Failure – If the physical host crashes, all VMs running on
      it fail.
  4. Complex Management – VMs require proper configuration, updates,
      and maintenance, making management difficult.

4. What is Paravirtualization?

Paravirtualization is a virtualization technique where the guest OS is modified to
work efficiently with the hypervisor. Instead of emulating hardware, the guest
OS communicates directly with the hypervisor using hyper calls.

Key Features:

      Reduces virtualization overhead, improving performance
      Requires guest OS modification
      Used in Xen and KVM hypervisors
