### Multiple-Choice Questions (MCQs)

1. **What is a media query in CSS3?**

 - A) A method to create animations

 - B) A technique to apply styles based on device characteristics

 - C) A way to define font styles

 - D) A method to create responsive images

 **Answer:** B) A technique to apply styles based on device characteristics

2. **Which of the following is a valid media query for devices with a maximum width of 768px?**

 - A) `@media (max-width: 768px) { ... }`

 - B) `@media (min-width: 768px) { ... }`

 - C) `@media only screen and (width: 768px) { ... }`

 - D) `@media (max-height: 768px) { ... }`

 **Answer:** A) `@media (max-width: 768px) { ... }`

3. **What does the `@media only screen and (min-width: 768px)` rule signify?**

 - A) Styles will apply only to screens wider than 768px.

 - B) Styles will apply only to screens narrower than 768px.

 - C) Styles will apply to all devices regardless of width.

 - D) Styles will apply only to print media.

 **Answer:** A) Styles will apply only to screens wider than 768px.

4. **In a mobile-first design approach, how are styles typically applied?**

 - A) Styles are applied for larger screens first.

 - B) Styles are applied for smaller screens first.

 - C) Styles are applied equally across all devices.

 - D) Styles are not applied at all.

 **Answer:** B) Styles are applied for smaller screens first.

5. **Which property is used to make an image responsive?**

 - A) `height: auto;`

 - B) `max-width: 100%;`

 - C) `width: 100%;`

 - D) All of the above

 **Answer:** D) All of the above

6. **What does the `background-size: cover;` property do?**

 - A) Scales the background image to fit the content area.

 - B) Stretches the background image to fill the entire area.

 - C) Scales the background image to cover the entire area while maintaining its aspect ratio.

 - D) Clips the background image to fit the area.

  **Answer:** C) Scales the background image to cover the entire area while maintaining its aspect
ratio.

7. **Which HTML5 element allows you to define multiple images for different screen sizes?**

 - A) `<img>`

 - B) `<picture>`

 - C) `<source>`

 - D) `<div>`

 **Answer:** B) `<picture>`

8. **What is the purpose of the `max-width` property for images?**

 - A) To prevent images from scaling up beyond their original size.

 - B) To stretch images to fill the container.

 - C) To set a fixed width for images.

 - D) To make images responsive only on mobile devices.

 **Answer:** A) To prevent images from scaling up beyond their original size.

9. **Which Bootstrap class is used to create a responsive table?**

 - A) `.table-responsive`

 - B) `.table`

 - C) `.table-striped`

 - D) `.table-bordered`

 **Answer:** A) `.table-responsive`

10. **What is the primary benefit of using Bootstrap for web development?**

  - A) It requires extensive coding knowledge.

  - B) It provides a mobile-first approach and responsive design features.

  - C) It is only compatible with certain browsers.

  - D) It does not support JavaScript.

  **Answer:** B) It provides a mobile-first approach and responsive design features.

11. **Which of the following is NOT a Bootstrap grid class?**

  - A) `.col-xs-*`

  - B) `.col-sm-*`

  - C) `.col-md-*`

  - D) `.col-xxl-*`

  **Answer:** D) `.col-xxl-*`

12. **What does the `.jumbotron` class do in Bootstrap?**

  - A) Creates a navigation bar

  - B) Displays a large box for calling attention to content

  - C) Styles buttons

  - D) Creates a footer

  **Answer:** B) Displays a large box for calling attention to content

13. **Which class is used to create a button group in Bootstrap?**

  - A) `.btn-group`

  - B) `.button-group`

  - C) `.group-button`

  - D) `.btn-set`

  **Answer:** A) `.btn-group`

14. **What is the default font size in Bootstrap?**

  - A) 12px

  - B) 14px

  - C) 16px

  - D) 18px

  **Answer:** B) 14px

15. **Which class is used to create a striped table in Bootstrap?**

  - A) `.table-striped`

  - B) `.table-bordered`

  - C) `.table-hover`

  - D) `.table-condensed`

  **Answer:** A) `.table-striped`

16. **What does the `.img-responsive` class do?**

  - A) Makes images circular

  - B) Makes images scale with the parent element

  - C) Adds a border to images

  - D) Changes the image source

  **Answer:** B) Makes images scale with the parent element

17. **Which of the following is a contextual class for success in Bootstrap?**

  - A) `.bg-danger`

  - B) `.bg-warning`

  - C) `.bg-success`

  - D) `.bg-info`

  **Answer:** C) `.bg-success`

18. **What is the purpose of the `data-ride="carousel"` attribute in Bootstrap?**

  - A) To pause the carousel

  - B) To start the carousel automatically

  - C) To stop the carousel

  - D) To change the carousel speed

  **Answer:** B) To start the carousel automatically

19. **Which class is used to create a disabled button in Bootstrap?**

  - A) `.disabled`

  - B) `.btn-disabled`

  - C) `.btn-inactive`

  - D) `.btn-off`

  **Answer:** A) `.disabled`

20. **What does the `.active` class indicate in a Bootstrap pagination?**

  - A) The link is disabled

  - B) The current page

  - C) The previous page

  - D) The next page

  **Answer:** B) The current page

21. **Which Bootstrap class is used to create a hover effect on table rows?**

  - A) `.table-hover`

  - B) `.table-striped`

  - C) `.table-bordered`

  - D) `.table-responsive`

  **Answer:** A) `.table-hover`

22. **What is the purpose of the `.lead` class in Bootstrap?**

  - A) To create a heading

  - B) To style a paragraph with larger font size

  - C) To create a button

  - D) To create a list

  **Answer:** B) To style a paragraph with larger font size

  - A) `<link rel="stylesheet" href="bootstrap.css">`

  - B) `<link rel="stylesheet"
