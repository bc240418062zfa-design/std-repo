10. Input hypothesis

Stephen Krashen’s theory that learners acquire language when they receive comprehensible input

11. Language death

Occurs when a language has no more speakers and ceases to be used.

12. Decreolisation

When a creole language gradually becomes more like the standard language from which it was
derived.

13. Language accommodation

Speakers change their language/speech style to match or diverge from their interlocutor.
