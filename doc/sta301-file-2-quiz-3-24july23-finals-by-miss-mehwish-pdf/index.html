**Question 1:**
In testing H0: µ = 100 against H1: µ ≤ 100 at the 10% level of significance, H0 is rejected if:
Options:

A. The p-value is greater than 0.10
B. 100 is contained in the 90% confidence interval
C. The p-value is less than 0.10
D. The value of the test statistic is in the acceptance region

Correct Option: C. The p-value is less than 0.10

**Question 2:**
The variance of the Hypergeometric distribution is:
Options:

A. pq{nk(N-k)(N-n)}/N*N(N-1)
B. npq{nk(N-n)}/N(N-1)

Correct Option: A. pq{nk(N-k)(N-n)}/N*N(N-1)

**Question 3:**
Alpha is the probability of:

Options:
A. Type I error
B. All of these
C. Committing Type I error

D. Rejecting H0 when H0 is true

Correct Option: A. Type I error

**Question 4:**

Which of the following is a major difference between the binomial and the hypergeometric
distributions?

Options:
A. The outcomes cannot be whole numbers in the hypergeometric distribution.
B. The probability of a success changes from trial to trial in the hypergeometric distribution.
C. The number of trials changes in the hypergeometric distribution.
D. The sum of the outcomes can be greater than 1 for the hypergeometric.

Correct Option: B. The probability of a success changes from trial to trial in the hypergeometric
distribution.

**Question 5:**
If the first moment ratio is equal to 0, then the distribution will be:
Options:

A. Symmetrical

B. Negatively Skewed
C. Positively Skewed
D. Leptokurtic

Correct Option: A. Symmetrical

**Question 6:**
If p is very small and n is considerably large then we shall apply the:
Options:

A. Binomial distribution
B. Exponential distribution
C. Poisson distribution
D. Hypergeometric distribution

Correct Option: C. Poisson distribution

**Question 7:**
In a normal distribution, how much area lies between μ±2σ?
Options:

A. 75%
B. 95.45%
C. 94%
D. 85%

Correct Option: B. 95.45%

**Question 8:**

A standard deviation obtained from the sampling distribution of sample statistics is known as:
Options:
A. Standard error
B. Universal error
C. Sampling error

D. Minimum error

Correct Option: A. Standard error

**Question 9:**

We can apply the method of Maximum Likelihood on:
Options:
A. Discrete as well as continuous variables
B. Continuous variables only
C. Qualitative variables only

D. Discrete variables only

Correct Option: A. Discrete as well as continuous variables

**Question 10:**
In a binomial experiment, the probability of success changes on:
Options:
A. 10th trial

B. Second trial
C. Each trial
D. 30th trial

Correct Option: C. Each trial
