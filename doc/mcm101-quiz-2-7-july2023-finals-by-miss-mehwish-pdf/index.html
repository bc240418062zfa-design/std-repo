1. When did Thomas Edison develop the kinetograph?
 a) 1895
 b) 1950
 c) 1989
 d) 1889
 Correct answer: d) 1889

2. A highly restrictive set of guidelines for movie content was promulgated in 1934 in America.
What was it popularly known as?
 a) James Code
 b) Hays Code
 c) Ethical Code
 d) Production Code
 Correct answer: b) Hays Code

3. How many columns does a classified ad usually consist of?
 a) Four columns
 b) Multiple columns
 c) Multiple columns
 d) Multiple columns

 Correct answer: b) Multiple columns

4. The world of civil rights spreading and voices were raised by:
 a) Politicians
 b) Sociologists
 c) Revolutionists
 d) Economists
 Correct answer: c) Revolutionists

5. Which newspaper department normally operates only at night?
 a) None of the given options
 b) Editorial
 c) Press
 d) Accounts
 Correct answer: c) Press

6. Which of the following media worked as a catalyst to gear up industrialization during the 18th
century in the European Continent?
 a) Television
 b) Computers
 c) Print media
 Correct answer: c) Print media

7. What would be a matter of great pride for a newspaper?

 a) High circulation
 b) Increase in the number of letters to the editor
 c) Increase in the number of employees
 d) Plenty of advertisements
 Correct answer: a) High circulation

8. In 1543, Nicolaus Copernicus wrote De revolutionibus; a work that placed:
 a) Planets revolving around Earth
 b) Sun at the center and the planets revolving around it
 c) Moon revolving around the Earth
 Correct answer: b) Sun at the center and the planets revolving around it

9. Which of the following is NOT the responsibility of the press?
 a) To manage all the technical aspects of printing
 b) To ensure that the newspaper would be printed before the deadline
 c) To monitor the distribution process of printed copies
 d) To ensure its availability for distribution the next morning
 Correct answer: a) To manage all the technical aspects of printing

10. Which area benefited the most from the extraordinary growth of mass media from the
seventeenth century?
  a) Public Relations
  b) Broadcasting
  c) Advertising

Correct answer: c) Advertising
