2. Predicate Logic:
Predicate logic is an extension of propositional logic that allows reasoning about
sets and variables.

      Predicates are truth-valued functions with variables, like C(x): x is a
       cat.
      You can bind variables using:
          o Substitution (e.g., C(Simba))
          o Quantification (e.g., ∀x ∈ Cats ● M(x))

It is useful to express general properties of elements in a set.

    Expressiveness: It should provide rich language features to accurately
     represent different system behaviors
    Automated: Automated tools should help with model checking and

     system.
