Qno7: Define SNP.
A SNP is defined as a single base change in a DNA sequence that occurs in a significant proportion (more
than 1 percent) of a large population.

Qno10: When does RFLP occur?

An RFLP occurs when the length of a detected fragment varies between individuals. Each fragment length
is considered an allele, and can be used in genetic analysis.
