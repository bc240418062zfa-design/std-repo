    Call by Reference
 A function in which original value of the

  variable is changed
 To call by reference we cannot pass

  value, we have to pass memory address
  of variable
 “&” is used to take the address of a

  variable

Example: Call by Reference

 {
        double x = 123.456 ;
        square ( &x ) ;
 }
   Value of ‘x’ is not passed , but the
