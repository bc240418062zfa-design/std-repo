1. INSERT INTO statement is used to enter values into__________.

 Options:

 a) Not null columns only

 b) Only particular column

 c) All columns

 d) Key value columns only

 Correct answer: c) All columns

2. From the following options, choose the correct statement for the third normal form.
 Options:

 a) Non-key attribute is dependent on another non-key attribute.

 b) There is partial dependency in the relation.

 c) There is redundant data in the relation.

 d) No non-key attribute is dependent on another non-key attribute.

 Correct answer: d) No non-key attribute is dependent on another non-key attribute.

3. If a relation is not in third normal form, then anomalies are due to ________.

 Options:
 a) Partial dependency

 b) Transitive dependency

 c) Reflexive dependency

 d) Full functional dependency

 Correct answer: b) Transitive dependency

4. Which of the following is a correct syntax for creating a Database named employee?
 Options:

 a) CREATE TABLE employee;
 b) CREATE TABLE employee;

 c) CREATE SQL DATABASE employee;

 d) CREATE DATABASE employee;

 e) CREATE MYSQL Database employee
 Correct answer: d) CREATE DATABASE employee;

5. ___________ SQL statement is used to enter values into columns.

 Options:

 a) ENTER INTO

 b) INSERT TOP

 c) PUT INTO
 d) INSERT INTO

 Correct answer: d) INSERT INTO

6. A relation is in third normal form if ________.

 Options:

 a) It is already in second normal form.

 b) It has multivalued attributes.

 c) It has a partial dependency.

 d) It has a transitive dependency.

 Correct answer: d) It has a transitive dependency.

7. Which of the following is NOT related to the basic SELECT statement?
 Options:

 a) FROM
 b) SELECT

 c) WHERE

 d) NOT NULL

 Correct answer: d) NOT NULL

8. A transitive dependency occurs when _________.

 Options:

 a) Part of the key is dependent on a key attribute.

 b) Non-key attribute is dependent on another non-key attribute.

 c) Non-key attribute is not dependent on another non-key attribute.

 d) Primary key attribute is dependent on a non-key attribute.
 Correct answer: b) Non-key attribute is dependent on another non-key attribute.

9. Which of the following is the correct syntax for creating a database table?

 Options:

 a) CREATE MYSQL TABLE name;

 b) CREATE TABLE name;

 c) CREATE TABLE;

 d) TABLE name CREATE;

 Correct answer: b) CREATE TABLE name;

10. __________ is a DML command.

 Options:
 a) SELECT

 b) CREATE
 c) ALTER

 d) DROP

 Correct answer: a) SELECT
