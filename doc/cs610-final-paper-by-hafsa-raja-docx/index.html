LAYERING AND TCP/IP PROTOCOLS
TCP/IP protocols are organized into five conceptual layers.
Physical layer 1: Corresponds to basic network hardware layer in OSI.
Network layer 2: Specifies how to organize data in frames.
Internet layer 3: Specifies the format of packets sent across an Internet and forwards packets.
Transport layer 4: Specifies how to ensure reliable transfer.
Application Layer 5: It specifies how one application uses an internet
