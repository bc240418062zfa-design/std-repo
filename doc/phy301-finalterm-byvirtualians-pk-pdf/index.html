      Explain KCL equations?

      KCL equation is written in nodal analysis to write nodal equation. To write KCL,
      we make use of Ohm’s law in the form of I=V/R

      At node (1)
                        V 1 /3k +4mA +2mA + (V 1 -V 2 ) /6k =0
      To simplify this equation, we take L.C.M. 6 and multiply each term by 6 on both
      sides. So

      6xV 1 /3k +6x 4mA +6x 2mA + 6x (V 1 -V 2 ) /6k =6x 0
      Solving this we get

                     2V 1 +24 +12 +V 1 – V 2 =0
                           3V 1 –V 2 = -36
       At node (2)
                             V 2 /4k + V 2 /12k - 2mA +(V 2 –V 1 )/6k = 0
      To simplify this equation, we take L.C.M. 12 and multiply each term by 12 on
      both sides. So

      12xV 2 /4k + 12x V 2 /12k - 12x 2mA +12x (V 2 –V 1 )/6k = 0
      Solving this we get

                            3V2 +V 2 – 24 + 2V 2 – 2V 1 = 0

      Linear circuit
      Linear circuits are proportional circuits having the output directly related to the
      input. In a linear circuit if we plot the Input vs Output of a circuit, it will be a
      straight line.

      For example if we increase the value of applied voltage across a linear circuit, the
      current flowing in the circuit will increase proportional to the applied voltage.
      Superposition Theorem
      Dear Student,
      The Superposition Theorem is an important concept in circuit analysis. It allows
      you to determine a voltage across a component or a branch current by calculating
      the effect of each source individually, and then algebraically adding each
      contribution.
      Superposition may be considered for circuit analysis when:
      There are two or more energy sources.
      The sources are either voltage or current sources.
      The circuit is not too complex.
      There are five steps used in applying the Superposition theorem to a circuit.

      What is simulation package?
      Simulation software is computer model based on the process of modeling a real or
      proposed system with a set of mathematical formulas. It is, essentially, a program
      that allows the user to do an operation through simulation without actually
      performing that operation.
      The simulation is time based, and takes into account all the resources and
      constraints involved, as well as the way these things interact with each other as
      time passes. Simulation also builds in the randomness you would see in real life.
      Simulation software is used widely to design equipment so that the final product
      will be as close to design specs as possible without expensive in process
      modification. Simulation software with real-time response is often used in gaming,
      but it also has important industrial applications. When the penalty for improper
      operation is costly, such as airplane pilots, nuclear power plant operators, or
      chemical plant operators, a mock up of the actual control panel is connected to a
      real-time simulation of the physical response, giving valuable training experience
      without fear of a disastrous outcome.

Thevenin's Theorem

      Any combination of batteries and resistances with two terminals can be replaced
      by a single voltage source e and a single series resistor r. The value of e is the
      open circuit voltage at the terminals, and the value of r is e divided by the current
      with the terminals short circuited.

Question:What is Thevenin's theorem ?Answer:

Thevenin's Theorem

      The Thevenin's theorem states that any linear network can be
      represented by a voltage source in series with an impedance. We will
      generally use a simpler version: any circuit made up of voltage
      sources, current sources and resistors can be replaced by a voltage
      and a resistor.
