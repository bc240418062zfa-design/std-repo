BIF501P | LAB 012 | Protein Structure Visualization-I

The RCSB PDB (Research Collaboratory for Structural Bioinformatics Protein Data Bank) is a
comprehensive and widely used repository that houses a vast collection of experimentally
determined three-dimensional structures of biological macromolecules. It serves as a primary
resource for researchers, educators, and students in the field of structural biology.

The RCSB PDB collects, validates, annotates, and distributes structural data obtained from
various techniques, including X-ray crystallography, NMR spectroscopy, and cryo-electron
microscopy. It provides access to a diverse range of biomolecules, including proteins, nucleic
acids, complexes, and small molecules.

Key features and functionalities of the RCSB PDB repository include:

   ✓ Data Access: Users can search and retrieve structures using various criteria, such as
     molecule type, experimental method, author, organism, and more.
   ✓ Structure Visualization: The repository offers integrated visualization tools, allowing
     users to explore and analyze structures directly within their web browser.
   ✓ Annotation and Metadata: Each structure in the RCSB PDB is meticulously annotated
     with metadata, including experimental details, ligands, secondary structure information,
     and functional annotations.
   ✓ Data Integration: The RCSB PDB integrates structural data with other resources, such as
     sequence databases, functional annotations, literature references, and protein family
     databases, to provide comprehensive contextual information.
   ✓ Education and Outreach: The repository offers educational resources, tutorials, and
     interactive tools to help students and researchers better understand structural biology
     concepts and techniques.
   ✓ Programmatic Access: The RCSB PDB provides programmatic access through web
     services and APIs, allowing developers to retrieve and analyze data programmatically.

functions, and exploring the relationships between structure, sequence, and biological activity. It

PyMOL:

PyMOL stands out as a predominantly open-source model visualization tool widely utilized in
the field of structural biology. The "Py" in its name signifies that the software is coded using the
Python programming language.

PyMOL has a wide range of applications in various scientific fields, particularly in structural
biology. Some of the key uses of PyMOL include:

   ✓ Molecular Visualization: PyMOL allows users to visualize and explore three-dimensional
     molecular structures, such as proteins, nucleic acids, and small molecules. It provides a
     comprehensive set of tools for rendering and manipulating molecular graphics.
   ✓ Protein Structure Analysis: PyMOL enables in-depth analysis of protein structures,
     including identifying secondary structures, measuring distances and angles, calculating
     surface areas, and performing electrostatic potential mapping.

How to Download PDB?

To access the RCSB PDB and download a specific protein structure, follow these steps:

   1. Open a web browser like Google Chrome or Mozilla Firefox.
   2. Type in the URL www.rcsb.org in the address bar and press Enter to navigate to the
      RCSB PDB website.

   3. On the RCSB PDB homepage, locate the search box and enter the ID "4P1E"
      corresponding to your target protein.
