  2. Write down the CFE string for Microsoft Windows 2007?

By Maha Rana

      The CFE string (Common Platform Enumeration - CPE Formatted Entry)
      for Microsoft Windows 2007 (likely referring to Windows 7) follows the
      standard CPE format used in cybersecurity tools like Qualys, Nessus, and
      NIST's NVD (National Vulnerability Database).

      cpe:/o:microsoft:windows_7

Breaking Down the CFE String:

     cpe:/o → Represents an operating system
     microsoft → Vendor name
     windows_7 → Product name

Example for Specific Editions:

     Windows 7 Professional:

      cpe:/o:microsoft:windows_7:professional

     Windows 7 Ultimate:

      cpe:/o:microsoft:windows_7:ultimate

  3. Block Cipher - 5 Points or Attacks:
        o   Block Ciphers: Encrypt data in fixed-size blocks (e.g., 128-bit).
        o   Common Block Cipher Algorithms: AES, DES, 3DES.
        o   Modes of Operation: ECB, CBC, CFB, OFB, CTR.
        o   Key Size: Larger key sizes provide better security.
        o   Attacks on Block Ciphers:
                  Brute Force Attack: Trying all possible keys.
