Question No 6
What is a Descriptor?

Answer: -
A Descriptor describes a Memory Segment by storing attributes related to a Memory Segment.
Significant attributes of a Memory Segment can be its base (starting) address, it length or limit and its
access rights.

Question No 7
Which data structure is derived from BPB and where it resides?
Answer: -
BIOS parameter block is a data structure maintained by DOS in the boot block for each drive. The boot
block is typically a 512 byte block which as seen the previous slides is the first logical block i.e. LSN = 0. It
contains some code and data. The data part constitutes the BPB.

Question No 12
Deleted Files using E5

Answer: -
DOS perform file deletion by placing 0xE5 at the first byte of it FCB entry and placing 0’s (meaning
available) in the entries for the file clusters in the FAT.

Question No 13
Write the structure of root directory
Answer: -
The DOS directory structure is a Tree like structure. The top most level of the tree being the root
directory. The root directory contains files and folders. Each folder can contains more files and folders
and so on it continues recursively
