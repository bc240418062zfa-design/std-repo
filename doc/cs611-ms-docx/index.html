CS611 ASSIGNMENT

Question-I

Suppose you are working as a software quality assurance engineer in a software house name XYZ Pvt. Ltd. Your company is developing point of sale “POS-Shop” for a grocery store. This system helps in smooth checkout for the customers and also this system maintain the inventory for the store. The implementation phase of the system has been completed and testing is underway.  You have to have to ensure the quality of the software you are developing.

During testing you found various problems in the software. Now you are required to classify these problems into errors, bugs, faults, defects and failures. You also have to provide solution for each.

Following tasks needs to be done.

A. Your task is to classify these problems into errors, bugs, faults, defects, and failures.
B. Also provide an explanation about your classification.
C. Propose solutions for each problem. Your solution include details about what needs to be done to fix the problem and prevent it from recurring?

    • Your task is to classify these problems into errors, bugs, faults, defects, and failures.
Problem 1: Users report that, during checkout, the total order cost is sometimes miscalculated and doesn't match the item prices in their cart.
Solution:
                Error
               Explained: This is a fault because the system is unable to effectively calculate the overall order cost.

Problem 2: When a customer adds an item to their wishlist, the system occasionally crashes, and an error message appears.
Solution:
Bugs :
Definition: This is a bug when the system frequently fails when an end user adds an item to its request.

Problem 3: In the product catalog, some items have missing images, even though they were uploaded by the administrator.
Solution:
Faults:
Explained: This is a bug that there is an error from expected behavior - photos are absent from the good's catalog notwithstanding being published.

Problem 4: Customers have encountered an issue where, upon attempting to log in, the system does not recognize their credentials and returns an "Invalid username or password" message. This occurs intermittently.
Solution:
Defect:
Explanation: This is an error caused by the computer's system failing to acknowledge acceptable privileges upon login, culminating in a "Inadmissible user or password" advance warning.

Problem 5: The search functionality works correctly most of the time, but occasionally it returns no results for valid queries.
Solution:
Failure:
Explanation: This is an outcome that the system is inconsistent with the criteria set forth. For valid searches, the search engine should frequently return responses.

    • Also provide an explanation about your classification.
Taxonomy Definition:

    • The bug:

Bugs represent programming mistakes which lead to unintended consequences. The overestimate of the total transaction cost in Problem 1 is a significant variation from the expected functioning, showing a fault in the code that does the calculation.

    • Fault:

Faults are defects in the functioning of a software program under particular conditions. The system crashing occasionally when adding items to the wishlist in Problem 2 indicates an error in the reliability of the system or execution of request-related actions.

    • Defects:

Defects are departures from the guidelines and anticipated behavior. In Problem 3, the missing images in the product catalog suggest a flaw since the system as a whole fails to show the images which the administrator had uploaded as planned.

    • Error:

Errors arise whenever an errors in the software leads to an incorrect outcome. Problem 4, in which the system fails to determine acceptable keys during login, is an error since it differs from the organized login behavior.

    • Failure:

Failures develop when the application fails to fulfill the minimum requirements. Problem 5 is a failure since the search capacity occasionally gives no results for acceptable inquiries, which does not always meet the stated goal of giving search results.

    •  Propose solutions for each problem. Your solution include details about what needs to be done to fix the problem and prevent it from recurring?

    • Bug(Problem 1 - Miscalculation of Total Order Cost):

Solution: Go over and over and fix the part of the code that calculates the entirety of the order cost. Implement thorough verification that guarantees precise numbers in a variety of settings.

    • Problem 2 (System Crashes Whenever Adding into The wish list):

Solution: Look at the stability of the system during wishlist operations. Identify and correct the code flaw that is causing those sporadic crashes. Implement extensive testing to ensure the stability of the wishlist functionality.

    • Defect (Problem 3 - Image Missing in Product Catalog):

Examine the image uploading and retrieval processes. Correct the code that is in charge of displaying photos in the good's catalog. Perform testing in order to guarantee that all supplied photos appear correctly.

    • Error (Problem 4 - Login Issue - Message "Inadmissible Account or Password"):

Solution: Go thru the username and password process for authentication again. Correct the code so that legitimate identification numbers are identified consistently. To check whether the issue has been successfully corrected, perform extensive testing using several login scenarios.

    • Failure (Problem 5 - Search Capability Returns No Results At times):

Assess the search algorithm and categorization methods. Resolve the problems that lead to irregular failures in the return of search results. Perform comprehensive testing in order to guarantee that the search functionality's trustworthiness.
