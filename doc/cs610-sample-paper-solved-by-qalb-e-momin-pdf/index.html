The Application Layer in the TCP/IP model is responsible for providing services like
email (SMTP), file transfer (FTP), and web browsing (HTTP/HTTPS). It interacts
directly with user applications.

// SMTP stands for Simple Mail Transfer Protocol.
It is used to send emails from a client to a server or between email servers.
