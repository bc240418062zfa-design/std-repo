Question #1: After fork() system call is made, parent and child processes have their
separate copy of ___________.

A) File mode creation mask
B) Environment
C) File descriptors
D) Nice value

Answer: B) Environment

Question #2: Which of the following two operations are provided by the IPC
facility?

A) Send & Delete message
B) Write & Delete message
C) Delete & Receive message
D) Receive & Send message

Answer: D) Receive & Send message

Question #3: Which of the following statements is not true regarding Cooperating
processes?

A) It may affect or be affected by any other process executing in the system.
B) It constructs the system in a modular fashion, dividing the system functions into
separate processes or threads.
C) It provides an environment to allow concurrent users to access the same resources.
D) It provides an environment to run parallel processes to speed up computation.

Answer: D) It provides an environment to run parallel processes to speed up
computation.

Question #4: The Operating system is a layer of software between _________ and
__________.

A) Dos, Windows
B) Kernel, hardware
C) Hardware, software application
D) Windows, Kernel

Answer: C) Hardware, software application

Question #5: Which of the following are TRUE for direct communication?

A) A communication link can be associated with exactly two processes
B) Exactly N/2 links exist between each pair of processes (N = max. number of processes
supported by the system)
C) A communication link can be associated with N number of processes (N = max.
number of processes supported by the system)
D) Exactly two links exist between each pair of processes

Answer: A) A communication link can be associated with exactly two processes

Question #6: A parent process calling _____ system call will be suspended until children
processes terminate.

A) Fork
B) Exit
C) Exec
D) Wait

Answer: D) Wait
Anonymous

Question #7: An operating system is easily portable between varying hardware
designs in _________ structural approach.

A) Micro kernels
B) Virtual Machines
C) Simple Layered

Answer: A) Micro kernels

Question #8: A ------- signal is generated when a write is performed to a FIFO that no
process is opened for reading.

A) SIGFIFO
B) SIGPIPE
C) Unnamed PIPE
D) Named PIPE

Answer: B) SIGPIPE
Anonymous

Question #9: A __________ system has well-defined, fixed time constraints, and if the
system does not produce output for an input within the time constraints, the
system will fail.

A) Real-time
B) Limited
C) Android
D) Operating

Answer: A) Real-time

Question #10: You can use the mv file1 file2 command to move ______________.

A) This command will create a copy of file1
B) file1 to file2.
C) This command will not work for moving files
D) file 2 to file 1

Answer: B) file1 to file2.

Question #1: What is used to request the OS by the process to take an I/O or initiating
child process?

a) Trap
b) Signal
c) System call
d) Interrupt

Answer: c) System call

Question #2: Which system call is used to write to a file or FIFO or any other IPC
channel?

a) read
b) write
c) fork
d) open

Answer: b) write

Question #3: The creating process is called a ________ process while the new processes
are called the ________ of that process.

a) Children, parent
b) None of the given options

c) Parent, children

d) Zombie, single

Answer: c) Parent, children

Question #4: Which of the following is not a major advantage of a multi-programming
system?

a) CPU utilization can be increased

b) More than one job can be processed at a given time

c) If more processes exist, the rest must wait until the CPU is free and can be
rescheduled

d) Jobs can be completed quickly

Answer: c) If more processes exist, the rest must wait until the CPU is free and can
be rescheduled

Question #5: You can use the mv file1 file2 command to move ______________.

a) file1 to file2.

b) file2 to file1.

c) This command will not work for moving files.

d) This command will create a copy of file1.

Answer: a) file1 to file2.

Question #6: Which of the following are TRUE for direct communication?

a) A communication link can be associated with N number of processes (N = max. number of
processes supported by the system).

b) Exactly two links exist between each pair of processes.

c) Exactly N/2 links exist between each pair of processes (N = max. number of processes
supported by the system).

d) A communication link can be associated with exactly two processes.
