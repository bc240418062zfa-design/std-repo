Here are additional multiple-choice questions (MCQs) covering various topics from the provided jQuery

11. **Which of the following is a method to manipulate CSS in jQuery?**

  - A) addClass()

  - B) removeClass()

  - C) css()

  - D) All of the above

  **Answer:** D) All of the above

12. **What does the `toggleClass()` method do?**

  - A) Adds a class to an element

  - B) Removes a class from an element

  - C) Toggles between adding and removing a class

  - D) Changes the CSS of an element

  **Answer:** C) Toggles between adding and removing a class

13. **Which jQuery method is used to get the value of form fields?**

  - A) text()

  - B) html()

  - C) val()

  - D) attr()

  **Answer:** C) val()

14. **What is the purpose of the `empty()` method in jQuery?**

  - A) Removes the selected element

  - B) Removes all child elements and content from the selected element

  - C) Hides the selected element

  - D) Changes the content of the selected element

  **Answer:** B) Removes all child elements and content from the selected element

15. **Which of the following methods can be used to create a sliding effect in jQuery?**

  - A) slideDown()

  - B) slideUp()

  - C) slideToggle()

  - D) All of the above

  **Answer:** D) All of the above

16. **What does the `parentsUntil()` method do?**

  - A) Returns all ancestor elements of the selected element

  - B) Returns all ancestor elements between two specified elements

  - C) Returns the direct parent of the selected element

  - D) Returns all sibling elements of the selected element

  **Answer:** B) Returns all ancestor elements between two specified elements

17. **Which method is used to stop an ongoing animation in jQuery?**

  - A) halt()

  - B) stop()

  - C) pause()

  - D) end()

  **Answer:** B) stop()

18. **What is the purpose of the `$.get()` method in jQuery?**

  - A) To send data to the server

  - B) To retrieve data from the server using an HTTP GET request

  - C) To load HTML content into an element

  - D) To manipulate CSS properties

  **Answer:** B) To retrieve data from the server using an HTTP GET request

19. **Which of the following is a valid way to include jQuery from a CDN?**

  - A) `<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>`

  - B) `<script src="jquery.js"></script>`

  - C) `<script src="http://ajax.googleapis.com/ajax/libs/jquery/1.11.3/jquery.min.js"></script>`

  - D) Both A and C

  **Answer:** D) Both A and C

20. **What does the `filter()` method do in jQuery?**

  - A) Selects all elements

  - B) Removes elements that do not match a specified criteria

  - C) Returns the first element of the selected elements

  - D) Returns the last element of the selected elements

  **Answer:** B) Removes elements that do not match a specified criteria

21. **Which of the following methods is used to attach multiple event handlers to an element?**

  - A) bind()

  - B) on()

  - C) click()

  - D) attach()

  **Answer:** B) on()

22. **What is the purpose of the `callback` parameter in jQuery methods like `fadeIn()`?**

  - A) To specify the speed of the effect

  - B) To define the element to be affected

  - C) To execute a function after the effect is completed

  - D) To set the opacity of the element

  **Answer:** C) To execute a function after the effect is completed

23. **Which jQuery method is used to retrieve the width of an element including padding?**

  - A) width()

  - B) innerWidth()

  - C) outerWidth()

  - D) getWidth()

  **Answer:** B) innerWidth()

24. **What does the `mouseenter()` method do?**

  - A) Triggers when the mouse leaves an element

  - B) Triggers when the mouse enters an element

  - C) Triggers when the mouse is clicked

  - D) Triggers when the mouse is double-clicked

  **Answer:** B) Triggers when the mouse enters an element

25. **Which of the following is NOT a jQuery AJAX method?**

  - A) load()

  - B) get()

  - C) post()

  - D) fetch()

  **Answer:** D) fetch()

26. **What is the purpose of the `noConflict()` method in jQuery?**

  - A) To create a new jQuery instance

  - B) To release the `$` identifier for use by other libraries

  - C) To prevent jQuery from running

  - D) To optimize jQuery performance

  **Answer:** B) To release the `$` identifier for use by other libraries

27. **Which of the following methods can be used to add new HTML content to an element?**

    - A) append()

    - B) prepend()

    - C) after()

    - D) All of the above

    **Answer:** D) All of the above

  28. **What does the `siblings()` method return?**

    - A) All child elements of the selected element

    - B) All parent elements of the selected element

    - C) All sibling elements of the selected element

    - D) All descendant elements of the selected element

    **Answer:** C) All sibling elements of the selected element

  29. **Which method is used to change the text content of an element?**

    - A) text()

    - B) html()

    - C) content()

    - D) change()

    **Answer:** A) text()

  30. **What does the `slideToggle()` method do?**

    - A) Hides an element

    - B) Shows an element

    - C) Toggles between sliding up and sliding down an element

    - D) None of the above

    **Answer:** C) Toggles between sliding up and sliding down an element
