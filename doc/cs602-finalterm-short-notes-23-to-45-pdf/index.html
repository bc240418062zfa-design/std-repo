LECTURE NO. 23 CS602

MATHEMATICS OF COLOR IN COMPUTER GRAPHICS

It is important to understand how color is represented in computer graphics so
that we can manipulate it effectively. A color is usually represented in the
graphics pipeline by a three-element vector representing the intensities of the
red, green, and blue components, or for a more complex object, by a four-
element vector containing an additional value called the alpha component
that represents the opacity of the color. rgb or rgba colors and mean a color
that's made up of either three or four elements. There are many different ways
of representing the intensity of a particular color element. Colors can also be
represented as floating point values in the range [0,1].
Rather than have an array with thousands of color entries, the images instead
contain explicit color values for each pixel. A 16-bit display is named since
each pixel in a 16-bit image is taken up by 16 bits (2 bytes): 5 bits of red
information, 6 bits of green information and 5 bits of blue information.
Incidentally, the extra bit (and therefore twice as much color resolution) is
given to green because our eyes are more sensitive to green. A 24-bit display,
of course, uses 24 bits, or 3 bytes per pixel, for color information. This gives
1 byte, or 256 distinct value each, for red, green, and blue. This is generally
called true color, because 2563 (16.7 million) colors is about as much as your
eyes can discern.
There is 32-bit color, something seen on most new graphics cards. Many 3D
accelerators keep 8 extra bits per pixel around to store transparency
information, which is generally referred to as the alpha channel, and therefore
take up 4 bytes, or 32 bits, of storage per pixel. Rather than re-implementing
the display logic on 2D displays that don't need alpha information, these 8 bits
are usually just wasted.
Representing Color

Before we can go about giving color to anything in a scene, we need to know
how to represent color Usually we use the same red, green, and blue (rgb)
channels discussed above, but for this there will also be a fourth component
called alpha. The alpha component stores transparency information about a
surface. Practically we will use two structures to ease the color duties: color3
and color4. They both use floating-point values for their components; color3
has red, green, and blue, while color4 has the additional fourth component of
alpha in there.
They have a fixed range. Each component can be anywhere between 0.0 and
1.0 (zero contribution of the channel and complete contribution). If

performing operations on colors, such as adding them together, the
components may rise above 1.0 or below 0.0.

WHY WE MIGHT WANT 128-BIT COLOR

128-bit color provides a wider color gamut than lower bit depth color modes (such as 24-
bit RGB). This means that 128-bit color can represent a greater range of colors and
shades, providing more accurate and vivid color representation. This is especially
important for high-end graphics applications, such as video and photo editing, where
accurate color representation is crucial. Additionally, 128-bit color also provides more
color precision, allowing for smoother color gradients and reducing the visibility of color
banding.

Clamping Color Values

Clamping color values refers to the process of limiting the range of colors used in an
image or a computer graphics program. It involves setting a maximum and minimum
limit for the values of each color channel (e.g., red, green, and blue), so that colors
outside of that range are "clamped" to the nearest limit. This can be used to prevent colors
from becoming too bright or too dark, and to maintain consistent color representation
across different devices. Clamping color values is an important step in color correction
and image processing.

Scaling Color Values by Intensity

Instead of clamping, we might want to scale the color by dividing by the largest color
value, thus scaling the rgb values into the [0,1] range. Scaling color values by intensity
refers to the process of changing the brightness or darkness of an image by multiplying
each color channel value by a scalar factor. The scalar factor is a value that represents the
desired level of intensity, and it is used to adjust the overall brightness of the image.
